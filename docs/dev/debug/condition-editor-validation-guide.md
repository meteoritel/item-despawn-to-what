# 条件树编辑器人工验收指南

本指南用于 Fabric 与 NeoForge 开发环境的游戏内验收。工程检查已覆盖 IDEA inspections、Kit 依赖边界和双平台 build；以下步骤仍需在游戏中执行。开始前准备两条可保存规则、包含多个动作和候选的规则、多个不同参数的条件，并备份规则配置。

## 验收步骤

1. 创建空 `AND`、空 `OR`，返回主编辑器后重新进入，再尝试保存。空组应保留并可继续加叶；未补齐时保存被拦截，补齐后可保存。
2. 打开未知叶与已知叶混合的条件树。未知叶内部参数只读，原始 JSON 完整保留；已知邻居仍可编辑。
3. 在 Number、Text、List、Climate、ItemCounts 等参数中输入非法或未完成内容，切换节点、切页、返回主编辑器后重新进入。输入应恢复，字段应标错，保存被拦截；修正后可以继续保存。
4. 折叠包含空组或错误的子树，再触发错误定位。完整树诊断不应因折叠减少，定位时应展开并选中正确节点。
5. 完成一次叶参数修改，检查叶摘要。摘要应与当前已接受草稿一致。
6. 从空树添加叶；删除或移走 `NOT` 的唯一子项。空树和空 `NOT` 都显示添加入口；`NOT` 壳保留，缺项时不能保存。
7. 在树视图与 JSON 视图之间切换。默认是树视图；JSON 只显示当前条件，保持缩进、只读、可复制，并与当前接受值一致。
8. 先输入非法参数再切到 JSON。JSON 应保留最近已接受值，并提示有未完成输入，不应输出非法文本。
9. 添加、查看、改参、删除、折叠、同级重排、跨父拖动，并执行多选批量整理。目标、层级、顺序和未选节点均应正确。
10. 尝试将节点移入自身、后代、叶、`NOT` 的第二项，或超出深度/节点/叶上限；随后取消拖动。非法落点显示简短原因，松手或取消后原树和历史不变。
11. 移动、复制、粘贴、包组未知叶，再只删除其中一个。未删除副本的未知字段必须完整保留，不注入默认字段。
12. 分别执行拖拽、批量删除、粘贴、包组，然后撤销和重做；再切视图、选中、折叠。每个实际结构操作应对应一条历史，纯视图操作、取消和无变化不应增加历史。
13. 在同一参数中输入多个字符后按 Enter 或失焦完成；连续完成两次滑条操作。每次完整编辑单独可撤销，配置历史不按字符拆分或错误合并。
14. 在四页、普通表单、大屏页和子弹窗中按 `Ctrl+Z`，分别测试文本框聚焦和非文本焦点。文本局部历史优先；否则撤销当前规则历史；一次按键只处理一次，弹层不穿透。
15. 使用 `Ctrl+Shift+Z`、`Ctrl+Y` 和鼠标撤销/重做按钮。三种重做入口结果一致，按钮 Tooltip 显示对应快捷键。
16. 分别修改规则 A、B 后切换规则并撤销。每条规则的历史应独立。
17. 在宽屏和窄屏进入大屏条件树页，切换参数区域，检查错误和 Tooltip。宽屏树与参数并排，窄屏可切换，控件可达且无重叠；文案只说明哪里错、怎么改。
18. 分别修改规则级条件、不同动作局部条件后返回保存；再对带未完成输入的动作或候选执行移动、删除、转换，并模拟跨规则服务端拒绝。条件作用域不混用，数组不丢项，输入随对象迁移，删除对象不留下幽灵错误；拒绝后草稿保留并定位到真实规则和字段。
19. 对照 [UI kit API](../internals/ui-kit-api.md) 检查页面实际使用的创建、查询、选择、移动、批量、codec 注入、回填和快捷键 API。回填不应产生编辑历史，公开约束与 Kit 边界检查结果一致。

## 记录方式

Fabric 与 NeoForge 各执行一遍；记录版本、规则样例、步骤编号、实际结果和截图/日志路径。任何失败都保留现场配置，先记录再修复，避免只记录修复后的结果。
