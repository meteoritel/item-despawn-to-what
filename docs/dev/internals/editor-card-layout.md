# 四阶段编辑页卡片布局

视觉参考为 [assets/editor-page-concepts/](assets/editor-page-concepts/) 下的四页概念图（概念图中的文案和交互不是实现依据）；字段、条件路径和撤销行为遵循 [编辑页契约](editor-pages-contract.md)。

- `RuleEditorScreen` 管理固定页头、全宽四页页签、状态标签和底部操作栏。编辑页外边距为 8，页签和底部按钮高为 22；底部按钮按实际文本宽度换行，单行时均分剩余宽度。
- `RuleEditorEditPages` 按实际内容高度生成 `PageCard`：基本信息一张；输入页为源物品、催化剂、流体三张；触发页为触发方式和触发条件两张；结果页为方案（多方案时）、执行动作与动作设置。一般卡片内边距、间距均为 8，标题区高为 20；基本页省去重复标题区，内边距为 6，规则 ID 用 0.8 倍字幅显示。
- `UiTheme.drawCard` 使用浅灰底、柔和单层描边和抗锯齿圆角，标题使用蓝色短标记；取消突出的黑白立体边与偏移阴影。`UiSegmentedControl` 用圆角蓝底白字显示选中项，取消白色上下边与下划线，键盘焦点以小点提示。底图位于 `textures/gui/editor/`，用 `tools/generate-editor-surfaces.py`（Python + Pillow）生成，32×32、九宫格角区为 8；圆角和描边不随整张卡片拉伸。
- 页面表单通过 `FormView.useCardSpacing()` 启用 20 的最小控件高度和 6 的行间距；基本页再用 `useCompactSpacing()` 调整为 18 的最小高度、4 的行间距和 64 的标签列。备注高为 36。卡片字段不再重复添加“默认”前缀；标题加粗，单行输入文字垂直居中。复合控件按内容测量，其它宿主保持默认密度。
- 表单目录按钮按本地化文本测量宽度；同排剩余控件宽度少于 64 时，按钮整体移到控件下面并按需换行。测量与命中矩形共用同一组按钮，按钮缓存仅在装配变化时更新。
- 输入页用 `CatalogSelectionControl` 替代物品引用字段的注册名列表和文本输入，展示物品图标与本地化名称；卡片按名称测宽，最大宽度 124、间距 4、高度 24，同排容纳多项，超宽换行。最多显示三行，再多可滚动；箭头键、Home/End 导航，右侧叉号或 Delete 移除。测量、绘制、命中共用卡片矩形，只在宽度或条目变化时重新排列。标签使用 `TagPreviewIcons` 的成员轮播，未知条目保留原始元素，注册名仅进入悬停提示；空列表仍有“添加”入口。
- 基本页显示名为空时，展示 `RuleNaming` 生成的实际默认名称；`TextControl.displayDefault()` 将它作为展示基线，未修改时保留字段缺失或原始空值，不把默认名写入 JSON。“恢复默认”删除自定义名并重建显示，尚未提交的自定义输入也可恢复。启用组件只占勾选框与标签的宽度，不显示 tooltip；优先级 tooltip 解释同一物品匹配多条规则时的尝试顺序：数值降序、条件数量降序、定义顺序。
- “黑名单”（`source.exclude`）行仅在 `source.items` 中存在有效标签时参与布局、焦点导航与命中。源物品增删后即时更新显隐，已有排除 JSON 不因隐藏而删除。添加入口使用 `SourceBlacklistPicker`，只从当前源标签的成员快照选择具体物品；各页只属于一个标签，大标签按 200 项拆子页，搜索按名称或 ID 在各标签内过滤。跨页选择按物品 ID 去重；空标签显示空状态，不能添加标签本身或无关注册表物品。目录状态栏按 Component 拼接本地化文本，避免打印 `translation{...}`。该弹窗与普通目录共用 `UiCatalogGrid` 样板、同一尺寸助手与同一套默认排除策略。
- 输入页目录统一为“添加”；对于允许标签的字段，`RuleEditorP4Panels.CatalogMapper` 合并普通目录与该字段所属注册表的标签。空搜索展示二者，普通文本搜索 ID／本地化名，`#` 开头只搜索标签。目录缓存或语言／资源变化时重建索引，每次文本变化只重新过滤和分页，不逐字符发送网络请求；合并后的结果共用 200 项分页上限，标签条目名称前置 `#`。选择页是占屏弹窗：自上而下为搜索框（有标签可选时右侧带一个范围轮询按钮，符号依次为 ◆ 只物品 / # 只标签 / ≡ 一起）、条目列表，底部一行与弹窗按钮同排；弹窗宽 280–440、内容高 120–300，按屏幕尺寸计算。条目按「图标 + 名称」分行排布，每行高 16、按页宽分 1–3 列，超过 16 像素的图标按比例缩进图标槽；名称超宽时在该行内悬停滚动，悬停提示只给条目信息：显示名一行、注册名一行，宿主附加说明（标签成员范围、实体预览不可用）另起一行，超过 240 像素再折行后交给原版定位。列表是内凹面板，偶数行用槽位底色、奇数行略亮形成隔行条纹，行数超过可见行时显示 4 像素滚动条，可直接拖动滑块或点击轨道跳转；已选条目整行浅蓝高亮并在行尾打勾。底部行由 `UiModal#inlineFooter()` 与 `UiFooterHost` 托管：最左是只画 `<`/`>` 的翻页按钮与页码（悬停给出完整按钮名），其后是分组标签／总数／已选与蓝色下划线的「清空已选」，右侧才是确认与取消，因此不再为翻页单独占一行。工具行与底部行各有一条分隔线。物品与流体的默认排除规则同处 `CatalogEntryPolicy`：物品隐藏空气与仅命令可得的技术性条目，流体只保留可放置的源流体（空流体与流动变体一律排除），规则固定生效、不提供界面开关。已有目录协议保持不变。
- `NumberControl` 的文本变化只预览合法值并更新滑条，回填通过抑制标记防止双向回调递归。Enter 或失焦按原有表单流程提交；Esc 恢复本次文本编辑前的值与文本。非法／未完成输入不钳制成合法值，仍阻止应用。卡片滑条增加手柄边框和刻痕。
- 数量对象逐引用一行：行首是物品图标与本地化名称（标签与未知引用显示原始注册名），随后是该引用的数量滑条与精确输入；不再逐行重复字段名，字段含义由卡片标题与标题行表达。名称列按全场最宽名称统一宽度（名称上限 100 像素、最多占行宽三分之一），精确输入框宽度也按各行最大值统一，使滑条上下对齐；名称超宽时在名称列内悬停滚动（起点与终点各停顿一次后往返），不再显示省略号，悬停图标给出完整名称、字段名与引用注册名。
- “源物品消耗”只保留“指定每轮消耗”入口；开启后每个已选源物品各占一行数量行，初始数量为 1。未指定时显示默认每轮消耗 1 个；若规则只声明其它消耗动作则显示不消耗源物品。已有消耗源物品动作时继续编辑原动作路径，说明数量由该动作设置，不能同时生成固定成本字段。
- 复选框保留自身标签；触发页的条件卡片显示只读缩进树与「编辑条件树」入口，铺满卡片内容宽度，结构编辑与叶参数都在画布页完成（见文末「画布页视觉规格」）。
- 触发选项横排并按宽度换行。有效触发不为空错误提示预留行；自然等待仅按既有规则显示。
- 结果页宽度达到 430 时分列，否则沿用方案／动作／详情导航；外层滚动条扣宽后会重新判断布局。普通产物预览缩为 24 高，实体预览保留 60 高。方案和动作列表保留独立滚动、选择、拖动与快捷键。
- 规则摘要和消耗提示移到页头悬停提示；通知仅出现时占用行高。编辑页不显示必填项数量横幅或独立的必填项清单；应用时继续校验缺失字段并通过既有问题定位流程处理。应用按钮由草稿改动和工作区状态决定是否可用。

卡片矩形与页面控件共用绝对滚动坐标，渲染受内容视口裁剪；底部操作栏不参与内容滚动。新增显示文本同步提供 `en_us` 与 `zh_cn`，数量对象通过规则 JSON 与服务端结算使用同一引用键；平台入口与 UI kit 公共接口保持原有职责。旧规则中已存储的排除项仍保持原有运行语义，界面限制针对新添加入口。

催化剂卡片中每个物品分别显示最低触发数量，所有引用均需达标；开启消耗后分别显示每轮数量，初始值采用各自门槛。增删引用同步数量对象，保留仍选中的值。流体卡片支持多选并显示任一种即可匹配的说明；目录与标签图标默认隐藏空流体与流动变体，立体图标使用真实材质和当前位置的方块染色，水在无可用染色时采用默认水色。
## 画布页视觉规格

大屏画布页（`ConditionTreeOverlay` + `UiConditionGraphEditor`）不复用上面的表单页卡片密度，规格如下（常量来源即这两个类）：

- **外壳分区**：顶部功能栏高 20、左缘工具列宽 20、底部状态栏高 14，分区之间留 1 像素缝隙。
- **画布**：底色比窗口底色深一档；点阵网格基准步长 16，实际步长 = 基准 × 缩放档位（50 / 100 / 150 / 200），网格锚定内容原点、随画布平移。
- **节点卡片**：两行文字（首行类型名 + 状态标记，次行参数摘要）；内容宽按文本测量后夹在 60–168；行高 10、上下内边距 2、1 像素描边，因此卡片高 24；层间距 42（卡片高 + 18），兄弟间距 12。
- **连线**：父卡片底到子卡片顶的正交折线（竖—横—竖三段），线宽与坐标都取整到屏幕像素。
- **热区**：非空容器末尾的小 `[+]` 为 12×12；空容器与空树中央的大 `[+]` 为 22×22。
- **类型选择浮层**：可搜索列表最大宽 220、行高 12、最多 8 行，另有 14 行高的标题与搜索行、12 行高的底部提示。分组 / 包组的 ∧∨ 小菜单复用同一行高与内边距，间距 4、最小宽 56。
- **内联参数框**：贴卡片下沿 6（内容像素），宽度取 max(卡片宽, 140)，高度按表单测量；下方越出视口时翻到卡片上方；展开 / 收起为 160ms ease-out，只改高度与透明度。
- **扁平皮肤**：`UiFlatPalette` / `UiFlatSkin` 只服务画布页与内联框——1 像素同色描边 + 灰阶层次，无立体凸凹与阴影；图标取自 `textures/gui/editor/icons_{dark,light}.png` 图集（单元格 16×16、2 列状态、14 行）。表单页仍用 `UiPalette` / `UiTheme`，两者互不影响。
- **画布配色归属**：画布本体、外壳与内联框的全部颜色都取 `UiFlatPalette` 的「条件树画布」段（卡片底色 / 描边、连线、强调色、热区、浮层、框选填充等），不直接引用 `UiPalette`；因此调整画布观感只改这一处，不会波及表单页。
