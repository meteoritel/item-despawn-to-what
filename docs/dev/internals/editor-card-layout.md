# 四阶段编辑页卡片布局

视觉参考为 [assets/editor-page-concepts/](assets/editor-page-concepts/) 下的四页概念图（概念图中的文案和交互不是实现依据）；字段、条件路径和撤销行为遵循 [编辑页契约](editor-pages-contract.md)。

- `RuleEditorScreen` 管理固定页头、全宽四页页签、状态标签和底部操作栏。编辑页外边距为 8，页签和底部按钮高为 22；底部按钮按实际文本宽度换行，单行时均分剩余宽度。
- `RuleEditorEditPages` 按实际内容高度生成 `PageCard`：基本信息一张；输入页为源物品、催化剂、流体三张；触发页为触发方式和触发条件两张；结果页为顶部方案工具条、执行行为与行为设置两张卡片。一般卡片内边距、间距均为 8，标题区高为 20；基本页省去重复标题区，内边距为 6，规则 ID 用 0.8 倍字幅显示。卡片头部（蓝条、可选图标、加粗标题、底部分隔线）统一由 `RuleEditorEditPages.drawCardHeader` 绘制，头部矩形由 `cardHeaderRect(x, y, width, inset)` 派生、高取 `CARD_HEADER_H`（20），蓝条宽 2、标题距蓝条 4、分隔线距头部下缘 5；几何全部相对头部矩形计算，因此各卡片的蓝条位置、标题基线与分隔线 y 坐标一致。内缩因页而异：结果页两栏与详情卡取 `RuleEditorResultsPage.DETAIL_PADDING`（6），其它三页取 `RuleEditorPageSupport.CARD_PAD`（8）。
- `UiTheme.drawCard` 使用浅灰底、柔和单层描边和抗锯齿圆角；取消突出的黑白立体边与偏移阴影。`UiSegmentedControl` 的选中段用浅蓝底 `selected` 九宫格（中心色取 `UiPalette.CONTROL_SELECTED`，即 `#9FB6CE`）、未选中段用 `control` 九宫格，段内文字统一取正文色 `TEXT_PRIMARY`（浅蓝选中底上白字对比度不足），键盘焦点在选中段左侧画 3×3 深色点；分段最外两侧各留 1 像素、相邻两段之间合计 2 像素。底图位于 `textures/gui/editor/`，用 `tools/generate-editor-surfaces.py`（Python + Pillow）生成，每张 32×32、九宫格角区为 8（切片参数留在 Java 侧，即 `UiTheme` 的 `UiNineSlice(..., 32, 8)`）；圆角和描边不随整张卡片拉伸。底图配色由该脚本从 `UiPalette.java` 的常量派生：card 中心取 `CONTROL_FILL`、control 中心取 `PANEL_FILL`、hover 中心取 `CONTROL_HOVER`、selected 中心取 `CONTROL_SELECTED` 且描边取 `ACCENT_PRESSED`、disabled 中心取 `CONTROL_DISABLED`；chip 的中心色与 card / control / hover / disabled 的中性描边色没有调色板来源，作为脚本内具名常量维护。任一调色板常量缺失或格式不符时脚本直接报错退出，不回落旧字面量，改调色板后重跑脚本即可对齐贴图。
- 窗口与卡片分属两个层级：模态窗口是系统级浮层，由 `UiModal` 以 `UiTheme.drawWindow` 绘制像素窗口外观、居中覆盖在页面上，并按 `UiRenderLayers` 的模态分层绘制（层步长 600，高于页面前景层），因此窗口必然盖住页面内容（含页面底部的通知行），通知不为浮到窗口之上另调层级；模态打开期间页面让出指针且不绘制页面提示与悬停提示；卡片是页面内容，绘制在页面内容视口内并受其裁剪，滚动只移动卡片内容。
- 页面表单通过 `FormView.useCardSpacing()` 启用 20 的最小控件高度和 6 的行间距；基本页再用 `useCompactSpacing()` 调整为 18 的最小高度、4 的行间距和 64 的标签列。备注高为 36。卡片字段不再重复添加“默认”前缀；标题加粗，单行输入文字垂直居中。复合控件按内容测量，其它宿主保持默认密度。标签列默认 88 宽并按可用宽度收紧到三分之一；行内自带文字的控件（复选框、数量对象、条件树）按自身标签宽度收窄该列，让出的宽度交给控件内部，其余行保持统一列宽以对齐控件左边缘。区间条与时间条端点行（`min` / `max`、`from` / `to`）的标签只写端点名（如起始 / 结束、最小 / 最大），时刻范围与可跨零点写在同组说明行里，避免标签超出标签列。
- 表单目录按钮按本地化文本测量宽度；同排剩余控件宽度少于 64 时，按钮整体移到控件下面并按需换行。测量与命中矩形共用同一组按钮，按钮缓存仅在装配变化时更新。
- 输入页用 `CatalogSelectionControl` 替代物品引用字段的注册名列表和文本输入，展示物品图标与本地化名称；卡片按名称测宽、最大宽度 124（只有一条时占满行宽）、间距 4、高度 24，同排容纳多项，超宽换行。最多显示三行，再多可滚动；箭头键、Home/End 导航，右侧叉号或 Delete 移除。测量、绘制、命中共用卡片矩形，只在宽度或条目变化时重新排列。标签使用 `TagPreviewIcons` 的成员轮播，未知条目保留原始元素，注册名的悬停提示带「注册名」前缀，显示名完全相同的条目（挂墙与悬挂告示牌）据此区分；空列表仍有“添加”入口。查不到本地化显示名的维度、群系等按资源路径给出人话名（`twilightforest:twilight_forest` → `Twilight Forest`），完整注册名与「注册名」前缀仍在悬停提示里。
- 基本页显示名只展示已填写文本，未设置时输入框为空，使用可选填写提示。启用组件只占勾选框与标签的宽度，不显示 tooltip；优先级 tooltip 解释同一物品匹配多条规则时的尝试顺序：数值降序、条件数量降序、定义顺序。
- “黑名单”（`source.exclude`）行仅在 `source.items` 中存在有效标签时参与布局、焦点导航与命中。源物品增删后即时更新显隐，已有排除 JSON 不因隐藏而删除。添加入口使用 `SourceBlacklistPicker`，只从当前源标签的成员快照选择具体物品；各页只属于一个标签，大标签按 200 项拆子页，搜索按名称或 ID 在各标签内过滤。跨页选择按物品 ID 去重；空标签显示空状态，不能添加标签本身或无关注册表物品。目录状态栏按 Component 拼接本地化文本，避免打印 `translation{...}`。该弹窗与普通目录共用 `UiCatalogGrid` 样板、同一尺寸助手与同一套默认排除策略。
- 输入页目录统一为“添加”；对于允许标签的字段，`RuleEditorPanelFactory.CatalogMapper` 合并普通目录与该字段所属注册表的标签。空搜索展示二者，普通文本搜索 ID／本地化名，`#` 开头只搜索标签。目录缓存或语言／资源变化时重建索引，每次文本变化只重新过滤和分页，不逐字符发送网络请求；合并后的结果共用 200 项分页上限，标签条目名称前置 `#`。选择页是占屏弹窗：自上而下为搜索框（有标签可选时右侧带一个范围轮询按钮，符号依次为 ◆ 只物品 / # 只标签 / ≡ 一起）、条目列表，底部一行与弹窗按钮同排；弹窗宽 280–440、内容高 120–300，按屏幕尺寸计算。条目按「图标 + 名称」分行排布，每行高 16、按页宽分 1–3 列，超过 16 像素的图标按比例缩进图标槽；名称超宽时在该行内悬停滚动，悬停提示只给条目信息：显示名一行、注册名一行，宿主附加说明（标签成员范围、实体与方块预览不可用）另起一行，超过 240 像素再折行后交给原版定位。列表是内凹面板，偶数行用槽位底色、奇数行略亮形成隔行条纹，行数超过可见行时显示 4 像素滚动条，可直接拖动滑块或点击轨道跳转；已选条目整行浅蓝高亮并在行尾打勾。底部行由 `UiModal#inlineFooter()` 与 `UiFooterHost` 托管：最左是只画 `<`/`>` 的翻页按钮与页码（悬停给出完整按钮名），其后是分组标签／总数／已选与蓝色下划线的「清空已选」，右侧才是确认与取消，因此不再为翻页单独占一行。工具行与底部行各有一条分隔线。物品与流体的默认排除规则同处 `CatalogEntryPolicy`：物品隐藏空气与仅命令可得的技术性条目，流体只保留可放置的源流体（空流体与流动变体一律排除），规则固定生效、不提供界面开关。已有目录协议保持不变。
- 所有字段目录（含源黑名单、条件叶参数、结果参数与子表单）在打开时回填草稿中的当前引用；`FormView.SelectionCatalogOpener` 传递确切字段路径及完整选择快照，`UiCatalogGrid.setSelection` 初始化勾选与计数。搜索、范围切换和分页保留已选集合；确认保存完整集合，取消勾选与清空均生效，未知非文本元素保留相对顺序与内容，取消弹窗不修改草稿。`FormPicker` 的候选列表同样标记当前值，并定位到第一个已选候选。
- `SourceCatalystSelectionPolicy` 为源物品和催化剂目录提供双向互斥快照：标签按客户端同步的成员展开，源黑名单排除优先；实际物品范围重叠的条目保留在列表中，灰色文字与黄色 `!`、悬停原因区别于自身已选的浅蓝底与勾号。冲突项禁止新增选择，已有冲突项允许取消；存在已选冲突时确认按钮禁用。成员与冲突判定按引用缓存，不逐帧重复展开标签。该限制作用于客户端目录选择，不修改服务端规则编解码或外部 JSON 的加载校验。
- `NumberControl` 的文本变化只预览合法值并更新滑条，回填通过抑制标记防止双向回调递归。Enter 或失焦按原有表单流程提交；Esc 恢复本次文本编辑前的值与文本。非法／未完成输入不钳制成合法值，仍阻止应用。卡片滑条增加手柄边框和刻痕。
- 数量对象逐引用一行：行首是物品图标与本地化名称（标签与未知引用显示原始注册名），随后是该引用的数量滑条与精确输入；不再逐行重复字段名，字段含义由卡片标题与标题行表达。名称列按全场最宽名称统一宽度（名称上限 100 像素、最多占行宽三分之一），这里的「行宽」是控件自身宽度——本行标签列已收窄到标签文本宽度；精确输入框宽度也按各行最大值统一，使滑条上下对齐；名称超宽时在名称列内悬停滚动（起点与终点各停顿一次后往返），不再显示省略号，悬停图标给出完整名称、字段名与引用注册名。
- 区间条与时间条（`UiRangeBar` / `UiCyclicTimeBar`）公开 `baseHeight()` / `preferredHeight()`：条内固定标签行 10、轨道行 12，时间条再加预设行 12；宿主按首选高度分配时聚焦提示独占一行，否则提示并入标签行内绘制，任何情况下都不会画到自身 `bounds` 之外。提示文案保持单行：两端齐全用「回车写入 · Esc 回退」，缺端用「有一端未设限 · 回车写入」。
- 高度条件参数只显示双端区间条，滑条窗口为 −64～512，不显示单独端点行与无约束说明。新增高度叶写入该明确区间；不限制高度时不添加高度条件。JSON 高度参数无世界高度上限，只保留整数格式、下限 −2048 与区间顺序校验；参数由 int 存储。窗口外的合法值在回填时保留，单端超出窗口时缺失端的预览随之扩展，不写回草稿。
- “源物品消耗”只保留“指定每轮消耗”入口；开启后每个已选源物品各占一行数量行，初始数量为 1。未指定时显示默认每轮消耗 1 个；若规则只声明其它消耗行为则显示不消耗源物品。已有消耗源物品行为时继续编辑原行为路径，说明数量由该行为设置，不能同时生成固定成本字段。
- 复选框保留自身标签、不再重复绘制行标签（布尔字段与气候开关同一处理，文案只出现一次），气候开关的文案前置一个空格以保证方框与文字有可见间距；触发页的条件卡片显示只读缩进树与「编辑条件树」入口，铺满卡片内容宽度，结构编辑与叶参数都在画布页完成（见文末「画布页视觉规格」）。
- 触发选项横排并按宽度换行。有效触发不为空错误提示预留行；自然等待仅按既有规则显示。
- 结果页顶部工具条提供当前方案／方案总数、组合方式（多方案时）、添加方案与方案操作，按实际本地化文案宽度换行；方案选择弹窗显示各方案的标题，工具条的方案按钮悬停显示当前方案的完整标题。工作区宽度达到 348（行为栏最小 128 + 间距 8 + 参数栏最小 212）时左右分栏，否则只在行为列表与参数之间导航；外层滚动条扣宽后重新判断布局。左栏宽为页面三分之一，夹在 128–184；列表使用与物品条目相同的圆角气泡底图，背景透明；气泡占满列表内容宽度，高 24、间距 4，选中与悬停状态由宿主主题绘制。气泡显示图标、序号与垂直居中的标题，隐藏左侧选中箭头；行间留白不触发选择、删除、tooltip 或拖动起始；行尾叉号直接删除对应行为，删除可撤销，命中先于列表选中和拖动排序。参数摘要只在悬停说明中展示，底部集中添加行为与更多操作。列表独立滚动并保留行为拖动排序与键盘导航；焦点描边仅围绕当前胶囊，容器与行间空白不接收鼠标焦点。
- 行为与条件类型选择共用 `UiTypePicker`：右侧滑入面板宽度上限 220、列表行高 18，包含搜索和滚动条；单击或 Enter 确认，Esc 或点击面板外取消。行为选择面板沿编辑内容可视区右缘定位，打开时独占输入，底层控件与 tooltip 不响应。
- 结果参数卡片以 18 像素图标及当前行为名作为标题，不另占一行绘制大预览；实体生成行为下方显示物品／实体／经验切换，其余行为按注册描述符显示实际参数。主参数与高级表单使用 18 的最小控件高度、4 的行间距、64 的标签列；高级按钮明确显示展开／收起状态；高级区分为「生成策略（当前方案）」与「行为参数（当前行为）」，仅在选中对应的通用实体或方块行为时显示相关方案策略。延迟显示单位为秒，单位文字独立预留轨道外宽度。行为卡片与参数卡片标题的悬停说明复用条件画布的自绘面板，按描述符逐行显示本地化参数与有效默认值；布尔、枚举、资源名称、百分比、秒数和条件摘要使用玩家可读格式，未注册行为只提示说明不可用，不复述原始 JSON。无行为时右栏显示添加行为提示；只读扩展行为保留提示和原始数据。左右分栏共用底边：右侧参数内容高度和左侧列表／按钮的最小高度共同确定卡片高度，左侧容器与底部按钮随右侧内容伸缩；两栏至少占满工作区剩余高度，参数较长时使用页面外层滚动。窄屏的单栏导航按当前页面内容分配高度。
- 规则摘要和消耗提示移到页头悬停提示；通知仅出现时占用行高。通知分三级（`RuleEditorScreen.NoticeLevel`）：INFO 以 5 秒计时（`NOTICE_INFO_TTL_MS`）、到点自动消失；WARNING 与 DANGER 常驻，直到被新通知替换、切换页面、打开模态或点击页签行时清除。INFO 以次要文字色直接绘制单行文本，WARNING 与 DANGER 绘制实心 chip（底色取警示色或危险色、文字取正文色、外框取控件立体暗边、左右各 3 像素内边距 `NOTICE_CHIP_PAD`）；调用点只给出级别，具体颜色由屏幕层按级别决定。编辑页不显示必填项数量横幅或独立的必填项清单；应用时继续校验缺失字段并通过既有问题定位流程处理。字段行的本地校验问题除标签改用警示色外，还在标签后补一段问题文案（标签至少保住 24 像素，宽度不足时只保留悬停提示）；说明行不参与校验问题提示，但说明文字超宽时悬停给出完整说明；标签被裁剪时（含行内控件与窄布局）悬停给出完整标签。应用按钮由草稿改动和工作区状态决定是否可用。

卡片矩形与页面控件共用绝对滚动坐标，渲染受内容视口裁剪；底部操作栏不参与内容滚动。新增显示文本同步提供 `en_us` 与 `zh_cn`，数量对象通过规则 JSON 与服务端结算使用同一引用键；平台入口与 UI kit 公共接口保持原有职责。旧规则中已存储的排除项仍保持原有运行语义，界面限制针对新添加入口。

催化剂卡片中每个物品分别显示最低触发数量，所有引用均需达标；开启消耗后分别显示每轮数量，初始值采用各自门槛。增删引用同步数量对象，保留仍选中的值。流体卡片支持多选并显示任一种即可匹配的说明；目录与标签图标默认隐藏空流体与流动变体，立体图标使用真实材质和当前位置的方块染色，水在无可用染色时采用默认水色。
## 画布页视觉规格

大屏画布页（`ConditionTreeOverlay` + `UiConditionGraphEditor`）不复用上面的表单页卡片密度，规格如下（常量来源即这两个类）：

- **外壳分区**：顶部功能栏高 22、左缘工具列宽 20、底部状态栏高 14，分区紧贴不留缝隙。内容区外围描一圈 1 像素外框，功能栏 / 工具列 / 状态栏与画布之间改用 1 像素分隔线；分隔线与画布自身描边同色，功能栏与下方区域的分隔线取画布顶框所在行、状态栏上缘的分隔线取画布底框所在行，这两行各自自左缘到右缘是一条连续线（工具列首格的顶行与顶部分隔线共行）。外壳底板取与承载它的模态面板同色的灰阶面，不再各区自画独立边框。功能栏高 22：外框 1 像素 + 图标格高 20（图标最大边 16 加每侧留白 2）+ 下侧余量 1 像素，图标格紧贴外框行下方；功能栏与下方区域的分隔线画在功能栏框外、与画布顶框同一行。功能栏底板只铺到最后一个图标格之后，右侧空白交还画布；底板绘制范围与命中范围分离，各格子的悬停高亮与点击命中仍按格子矩形。
- **画布**：底色比窗口底色深一档；点阵网格基准步长 16，实际步长 = 基准 × 缩放档位（50 / 100 / 150 / 200），网格锚定内容原点、随画布平移。
- **节点卡片**：卡片内部自上而下为居中标题带（高 10）、1 像素分隔线与固定两行内容区（行高 10）：标题带放条件叶的类型名或容器的运算符（`且` / `或` / `非`，容器语义只由运算符表达、内容行不再重复），内容首行放条件叶的参数摘要或容器的分支计数（「N 个分支」/「暂无条件」），内容次行放结构标记（`[不完整]` / `[超限]` / `[层级较深]`，无问题为空）。标题、摘要与结构标记三者中最宽者为内容宽测量依据，结果夹在 60–168；上下内边距 2、描边 1 像素，因此卡片高 35；层间距 53（卡片高 + 18），兄弟间距 12。描边常态为 1 像素卡片描边色，悬停未选中为 1 像素强调色，选中为 2 像素强调色，结构问题使用错误色，优先级为 选中 > 结构问题 > 悬停。条件叶、容器与两个只读端点共用同一套内部纵向分区，超长文本按宽度裁剪。
- **悬停提示**：画布卡片悬停显示自绘面板（`UiDescriptionTooltip`）：标题行用正文色（结构问题时用错误色）、摘要行用次要文字色、结构标记行另起一行用错误色；面板底色与 1 像素描边取浮层配色，层级高于画布内容与侧栏，越出画布时向内侧翻转并钳制在画布内。功能栏、工具列与内联参数框字段的悬停提示仍走原版 tooltip。
- **帮助浮层**：功能栏的问号格切换（`ConditionTreeOverlay`）。面板宽度按正文测量，夹在 160 与画布可用宽度之间；正文 7 条动作条目各以两字动作标签开头（新增 / 编辑 / 选择 / 移动 / 视图 / 平移 / 关闭），说明先按「内宽扣掉标签列」的可用宽度折行再绘制，逐行都不裁剪。标题取 `helpText`、说明取 `helpTextMuted`；浮层是模态的，任意点击或 `Esc` 关闭。
- **连线**：父卡片底到子卡片顶的正交折线（竖—横—竖三段），线宽与坐标都取整到屏幕像素。
- **热区**：非空容器末尾的小 `[+]` 为 12×12；空容器与空树中央的大 `[+]` 为 22×22。
- **类型选择浮层**：条件与行为共用 `UiTypePicker` 的可搜索侧栏，最大宽 220、列表行高 18、按可用高度裁剪，标题与搜索行高 14、底部提示行高 12。分组 / 包组的 ∧∨ 小菜单行高 12，间距 4、最小宽 56。
- **内联参数框**：从画布右缘滑入的侧面板，宽度取 `min(220, 画布宽)`、高度取满画布；展开 / 收起为 160ms ease-out，动画只改滑入位置。标题行 14、内边距 4，表单内容宽 = 面板宽 − 8（面板取到上限 220 时表单宽 212）。表单沿用默认密度（卡片密度只由卡片编辑页启用），标签列默认 88、按可用宽度收紧到三分之一；说明行与其它行一样保留该标签列（`FormRowLayout.rowLabelWidth` 对 `EditorFieldType.NOTE` 返回统一列宽），因此 212 宽时标签列 70、说明行绘制宽 = 212 − 70 − 4 = 138；出现 4 像素滚动条时表单宽 208、标签列 69、说明行 135。说明文字必须收进该宽度，放不下时由悬停提示给出全文。
- **扁平皮肤**：`UiFlatPalette` / `UiFlatSkin` 用于画布页、内联框与共用类型选择侧栏——1 像素同色描边 + 灰阶层次，无立体凸凹与阴影；图标取自 `textures/gui/editor/icons_{dark,light}.png` 图集（单元格 16×16、2 列状态、14 行）。表单页仍用 `UiPalette` / `UiTheme`，两者互不影响。
- **画布配色归属**：画布本体、外壳与内联框的全部颜色都取 `UiFlatPalette` 的「条件树画布」段（卡片底色 / 描边、连线、强调色、热区、浮层、框选填充等），不直接引用 `UiPalette`；因此调整画布观感只改这一处，不会波及表单页。
