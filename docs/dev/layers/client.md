# 抽象层：客户端（编辑工作区 · 界面 · UI kit）

> 覆盖 `client/net`、`client/edit`、`client/key`、`client/ui`（`kit` / `theme` / `widget` / `screen` / `screen/form` / `prototype`）。
> 面向改编辑器与改 UI kit 的开发者。类级契约见 [../internals/editor-pages-contract.md](../internals/editor-pages-contract.md)、
> [../internals/ui-kit-api.md](../internals/ui-kit-api.md)、[../internals/editor-card-layout.md](../internals/editor-card-layout.md)。

## 1. 定位与隔离

客户端只做三件事：**收发编辑协议、在本地草稿上编辑、把草稿画出来并接受输入**。
它不执行规则，不拥有权威数据；服务端始终是规则与落盘的唯一权威。

四条边界：

1. **端隔离**：内核不引用客户端；客户端经协议载荷与静态 sink 与内核通信。
2. **层内单向**：`client/net`（协议）→ `client/edit`（草稿与注册表）→ `client/ui`（界面）；界面层不得直接接触传输载荷类型。
3. **UI kit 边界**：kit 是可被宿主依赖的独立边界，只依赖 Minecraft 客户端通用类型、Java 标准库、JOML、LWJGL 与极少数精确允许的渲染类型；
   **不依赖本模组任何其它包、不依赖加载器 API、不依赖 Gson 业务对象**。边界由脚本强制校验（见 [conventions.md](../conventions.md)）。
4. **宿主注入**：主题、文案、图标、渲染器、指针与键盘快照全部由宿主传入；kit 不硬编码任何本模组的语言键。

## 2. `client/net`：协议工作区

| 组件 | 职责 |
|---|---|
| 协议工作区 | 客户端侧的编辑会话状态：会话标识、协议版本、当前版本戳、最近回执与问题、目录缓存 |
| 上行构造 | 组装确认、心跳、关闭、快照请求、目录请求、变更集（含超限分片）等上行载荷 |
| 下行分发 | 注册并接收开屏、快照、分片、目录、回执五类下行载荷，分派给工作区 |
| 开屏入口 | 服务端开屏载荷的**唯一**客户端入口：校验协议版本与状态码后转换为"打开编辑器"请求 |

- 服务端下发的开屏载荷在**取锁失败时也会下发**（带失败状态码与空会话标识），客户端据此提示当前持有者。
- 客户端状态与界面之间通过只读工作区视图交换：视图**不暴露任何传输载荷类型**，
  界面只按状态码派生出的保存状态分支，**禁止解析文案**。
- 断线、会话失效、租约到期都会让工作区回到"未持有"状态，界面据此禁用编辑与应用。

## 3. `client/edit`：草稿与编辑器注册表

| 组件 | 职责 |
|---|---|
| 规则草稿 | 单条规则的本地可编辑形态：解析自快照三视图，保留未识别字段与原始内容 |
| 编辑会话（撤销栈） | 草稿修改的唯一入口：记录前深拷贝快照，仅在真实变化时压栈；撤销 / 重做是整份草稿快照置换 |
| 类型编辑器注册表 | 类型标识 → 编辑器描述（字段、默认值、标签、校验提示）；用于条件与效果两类 |
| 编辑器描述与预设 | 描述单个类型的可编辑字段、数值域、预设取值与本地化标签 |
| 草稿持久化 | 未应用的草稿落盘到本机 config 目录，支持重启 / 断线恢复与冲突判定 |
| 客户端类型注册表 | 客户端侧识别内置类型集合，供注册表填充与回退判定 |

**关键契约**：

- **未注册类型不报错**：注册表对未识别的类型返回只读回退描述（展示原始内容摘要并原样保留未识别字段），
  使第三方扩展类型仍可在界面中被看到而不被破坏。
- **撤销粒度是字段级**：表单逐字段比较，每个真实变化的字段单独入栈；一次弹窗确认包含多个字段改动时，需要多次撤销。
- **撤销栈有上限**；草稿持久化只存本机中间态，不写服务端目录、不写覆盖层；持久化格式损坏时跳过而不是抛异常。

## 4. `client/ui`

### 4.1 `ui/kit`：声明式组件边界

kit 提供内容排版、控件与交互、输入上下文与捕获、数值策略、滑块核心、焦点、导航、灯箱、实体与方块预览、图标轮播、绘制层级与命中几何；
另附无业务语义的装配示例类。约束与约定：

- **输入路由固定顺序**：顶层模态作用域 → 该作用域的捕获目标 → 聚焦控件 → 容器导航；任一环节消费即停止，**同一事件只被消费一次**。
- **捕获生命周期**：一个输入作用域同时只允许一个捕获目标；统一结束原因涵盖释放、取消、隐藏、禁用、卸载、焦点作用域切换与宿主关闭。
  宿主必须在隐藏 / 禁用 / 卸载 / 关闭时走统一结束入口，否则会残留捕获与未提交预览。
- **操作生命周期**：单值操作区分"开始 / 预览 / 提交 / 取消"；回填不产生事件、单动作单提交、无变化无历史。
- **数值策略与显示窗口分离**：数值策略表达"哪些值合法、按几档吸附"，是提交与校验的唯一依据；
  显示窗口只表达"哪一段铺在轨道上"，**不得当作提交硬限额**。
- **预览能力**：实体与方块预览只负责绘制，不创建实体、不运行 tick、不加入世界；失败时返回失败由宿主画兜底并说明，缓存与失效由宿主负责。
- **绘制层级**：背景 / 图标 / 前景文字 / 原版提示 / 模态各占固定层，由作用域管理而非绘制先后；层级负责视觉遮挡，输入隔离仍须单独实施。

### 4.2 `ui/theme` 与 `ui/widget`：宿主适配层

- `ui/theme` 是灰色像素主题：把调色板映射成 kit 所需的样式对象后注入；只依赖 Minecraft 客户端通用类型与 kit，不依赖内核与平台 API。
- `ui/widget` 在 kit 之上提供可直接使用的输入框、多行文本域、列表、树、弹窗、按钮变体、滑块、区间条、周期时间条、条件树编辑器等；
  所有控件遵循统一的"渲染 / 输入"契约，由宿主屏幕统一转发鼠标、键盘与滚动事件。
- 控件层把 kit 的核心语义包装成兼容旧签名的公开接口（滑块 / 区间条 / 周期条都是对 kit 核心的委托），
  **界面因此已实际使用 kit 的标量、区间与周期核心**。
- **鼠标释放归属契约**：容器记录本次按下命中的控件，释放与拖动只派发给该归属；没有归属时不派发、不广播。
  弹出层在其存续期间是**唯一事件所有者**，此时释放交给弹出层；关闭弹出层必须清掉归属状态。
  禁止为单个按钮在其释放回调里写绕过归属的特例。
- **文本长度按 Unicode 码点判定**（超限整体拒绝、不截断、经溢出回调上报）；程序回填必须完整，并在回填后从开头显示。

### 4.3 `ui/screen`：编辑器界面

| 界面 | 职责 |
|---|---|
| 规则编辑器屏幕 | 固定页头、四页页签、状态标签与底部操作栏；切页前先提交有效编辑并过导航门禁 |
| 编辑页（四页） | 基本页（身份与元信息）、输入页（来源与消耗、催化剂与流体的存在条件、消耗参数）、触发页（触发方式、延迟、条件树结构）、结果页（组合方式、方案与动作参数） |
| 叶弹窗面板 | 某个条件叶的参数编辑：目录选择、区间 / 周期控件、数量控件与说明行 |
| 表单视图 | 字段级编辑、行内校验提示、目录选择按钮、复选与数值控件、行尾操作按钮 |
| 预览图标 | 物品 / 方块 / 实体 / 流体 / 标签成员 / 规则配方的预览与缓存 |

**四页契约要点**：

- 存在条件（催化剂、流体）在**输入页**是唯一入口；勾选即在**规则级条件树**新增一个存在条件叶（保留既有根的整体语义），取消勾选删除该类型的规则级存在叶。
- **输入页与触发页之间不存在类型副本**，也不按"类型相同"匹配：两侧都按**确切叶路径**指向同一份草稿内容，
  因此同名同类型的多个叶各绑各的路径。触发页只负责叶的**结构**（增删 / 取反 / 组合），叶的**参数**在叶弹窗里编辑。
- 结果页**不重复**消耗参数：消耗类动作的数量参数归输入页；概率、延迟与效果级条件仍在结果页。
- 新建空白规则落在输入页；从模板新建或打开已有规则落在基本页。
- 界面关闭与释放：屏幕关闭、切换页签、工作区冻结时必须结束捕获与未提交预览。

## 5. `client/key`

定义客户端按键（类别与打开界面）。默认不绑定具体键位，由用户自行设置；
按键触发只是"请求打开编辑器"的入口之一，实际开屏仍须经服务端取锁与开屏载荷。

## 6. 已知限制

- kit 尚未拆为独立 Gradle 模块与发布坐标（只冻结边界与检查方式）。
- 条件树叶行本身不显示编号：编号只出现在输入页的存在条件标题与叶弹窗标题。
- 输入页只列出**规则级**存在叶；动作局部存在叶只能在触发页条件树里逐叶进入弹窗编辑。
- 显示名 / 备注在极端粘贴（一次性超过两倍码点上限的补充平面字符）时可能被原版文本框静默截断到上限而不提示；
  逐字符键入与常规粘贴不受影响，上限判定本身仍按码点。
- `ui/prototype` 是开发期原型界面，**不属于生产界面**：不得注册快捷键，也不得被绕过独占锁的入口打开。

## 7. 扩展点

| 要做什么 | 落点 | 约束 |
|---|---|---|
| 支持新的条件 / 效果类型 | `client/edit` 的类型编辑器注册表 + 编辑器描述 | 未注册类型自动走只读回退，不需要改界面框架 |
| 新增界面控件 | `ui/kit`（可复用语义）或 `ui/widget`（宿主适配） | kit 不得引入项目包与加载器 API；边界脚本必须通过 |
| 新增字段行 / 行尾操作 | `ui/screen/form` | 走字段级撤销，不写释放特例 |
| 新增页 / 调整布局 | `ui/screen` | 保持四页职责与"输入页为存在条件唯一入口"的契约 |
