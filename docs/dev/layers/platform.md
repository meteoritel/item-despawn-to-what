# 抽象层：平台接入（引导 · 平台抽象 · 事件与 Mixin · 配置）

> 覆盖 `platform/`、`fabric/`、`neoforge/` 与 `core/config`。
> 类级映射与两端差异明细见 [../backend/modules/platform.md](../backend/modules/platform.md)、
> 隔离机制见 [../backend/systems/platform-abstraction.md](../backend/systems/platform-abstraction.md)。

## 1. 定位

平台层**只做入口**：把加载器的事件、网络、命令与客户端引导转发给内核，不含业务逻辑。
所有业务判断（哪些伤害算环境销毁、是否接管自然消失、是否允许转化）都在内核，平台层只负责"在正确的时机调用内核"。

## 2. 三种注入方式

| 方式 | 方向 | 用途 | 契约 |
|---|---|---|---|
| 平台能力契约 | 内核调用平台 | 环境判定、配置目录、向玩家发包、实体状态存取 | 单一接口 + 服务发现实现；未实现平台静默降级 |
| 窄接口 | 平台实现、内核消费 | 命令层与编辑层需要的运行时能力 | 内核定义最小能力集，平台侧以匿名实现提供 |
| 静态 sink | 平台 / 客户端安装 | 服务端主动触达客户端（开屏、快照、回执、目录） | 内核暴露安装入口，客户端安装回调；未安装即空操作 |

**为什么这样设计**：内核不必依赖平台运行时类，也不必引用客户端；平台侧无需把运行时内部状态提升为公共 API。

**约束**：窄接口的所有成员在服务端完全就绪前都可能返回空值；平台能力契约装配失败是硬错误（服务发现文件必须随包发布）；
实体状态的读写位于伤害判定等热路径，**必须静默降级、绝不抛异常**。

## 3. 引导与生命周期持有者

两端各有一个同名的静态持有者（`RuleRuntimeHost`），暴露相同的语义方法名，作为内核的**唯一入口**：

| 阶段 | 语义 |
|---|---|
| 启动 | 先释放上一轮 → 读取模组级配置 → 构建内置类型注册表 → 创建运行时（注入平台寿命提供者）→ 加载三层规则 → 替换索引 → 注入掉落物状态时长 → 对全部已加载维度回扫。**必须等服务端全部维度创建完成**，否则会漏掉启动期已存在的掉落物 |
| 重载 | 重建索引 + 全维度回扫 + 推进覆盖层版本戳；**失败时保留旧索引**并回报失败 |
| 停止 | 释放全部维度状态、复位编辑服务端处理器、把实体状态时长复位为不授予（避免同进程下一个服务端实例沿用旧配置） |
| 事件转发 | 掉落物入世界 / 离开、自然到期接管、环境致死请求、服务端 tick、维度加载 / 卸载 |

**单一 tick 推进入口**：所有维度共享一份预算，因此只在"服务端 tick 结束"事件里推进一次；
推进顺序固定为"开始运行时 tick → 推进运行时 → 推进调试会话 →（周期性）清理空闲编辑会话"，不按维度重复推进。

**配置路径**：覆盖层目录由模组级配置指定；但模组级配置文件自身的位置固定，不受该字段影响，避免引导期自引用。

## 4. 事件即调用时机

| 需求 | Fabric | NeoForge |
|---|---|---|
| 服务端就绪 | 服务端启动事件 | 服务端启动事件 |
| 服务端停止 | 先关闭调试会话，再关闭运行时 | 同左 |
| 数据包重载 | 数据包重载完成且成功才重建 | 数据包同步事件、且仅服务端侧 |
| 掉落物入世界 / 离开 | 实体加载 / 卸载事件 | 实体加入 / 离开世界事件 |
| 自然消失接管 | Mixin（无原生等价事件） | 原生到期事件 + 延长寿命 |
| 环境伤害保护 | Mixin | 原生无敌判定事件 |
| 环境致死请求转化 | Mixin | Mixin（两端注入描述符不同） |
| 死亡掉落排除 | 两个 Mixin + 死亡判定标记 | 原生掉落事件直接打标记 |
| 服务端 tick | 服务端 tick 结束事件 | 服务端 tick 事件（后） |
| 维度加载 / 卸载 | 世界加载 / 卸载事件 | 维度加载 / 卸载事件 |
| 包层判定（内置 / 世界） | 查加载器模组列表 | 按包标识前缀判定 |

## 5. Mixin 使用原则

**优先使用已有事件；确无等价事件才写 Mixin，且 Mixin 只作入口。**

- Mixin 内不写业务逻辑：只调用内核的接管 / 请求 / 状态门面方法。
- 两端回调签名不同时各自写独立注入描述符，不强行共用。
- 当前 Mixin 承担三类无法用事件表达的能力：自然到期销毁拦截、环境致死真实分支转发、掉落物合并兼容（永久标志不一致禁止合并、临时状态取并集）。
- 平台层只判定"是否关键致死点"，**伤害分类表在内核中唯一维护**，平台不重复定义伤害类别。

## 6. 两端差异摘要

| 维度 | 差异 |
|---|---|
| 自然消失接管 | Fabric 用销毁拦截；NeoForge 用原生到期事件并延长寿命 |
| 环境伤害保护 | Fabric 用受伤头部拦截；NeoForge 用原生无敌判定事件 |
| 掉落物状态持久化 | Fabric 用持久化数据附件；NeoForge 用实体持久化数据；内核只经统一状态门面访问 |
| 寿命取值 | Fabric 无加载器提供的物品寿命接口，使用配置兜底刻数；NeoForge 读取实体当前寿命，保留其它模组修改 |
| 包层判定 | 按模组列表或包标识前缀 |
| 客户端引导 | Fabric 有独立客户端入口类；NeoForge 用客户端侧事件订阅完成接线 |
| 网络下行处理 | Fabric 由客户端注册器接收；NeoForge 由客户端侧处理并只做路由分发（不引用客户端类） |

**共同点**：启动 / 重载 / 关闭、掉落物事件、环境致死请求、tick、维度加载卸载的**语义口径两端一致**；
保存后的重建走同一条重载路径；状态结构与伤害类别只在内核定义一次。

## 7. 网络与协议注册

- 协议版本两端必须对齐；握手不一致即拒绝。
- C2S 与 S2C 的**类型**都必须在公共初始化注册，否则专用服务端连接协商会判定通道缺失。
- 平台侧下行处理器只做路由分发，不引用客户端类；客户端未安装 sink 时静默丢弃。
- 玩家断线只清理该玩家的分片缓存；编辑会话按其租约到期释放。

## 8. 模组级配置（`core/config`）

模组级配置与规则配置完全分离，两端共用同一实现与同一份文件；未知键忽略、缺失键取默认，文件缺失时写出默认值方便用户直接编辑。
按语义分为五组：

| 分组 | 作用 |
|---|---|
| 调度预算组 | 每 tick 软时间预算、全局工作量上限、效果类单独限额、到期搬运平滑窗口与批量、位置搜索每刻上限；**在运行时构造时读取一次，改动需重启服务端** |
| 检查与寿命组 | 失败退避基数与上限、Fabric 端寿命兜底刻数 |
| 实体状态组 | 新产物临时保护时长、转化冷却时长（引导时注入；取 0 表示不授予） |
| 调试组 | 常规运行日志开关、开发场景准备批量与准备软预算；**不参与**每 tick 运行时预算 |
| 邻域产物阈值 | 所有规则共用的开组准入阈值（物品 / 通用实体 / 经验球的数量与统计半径）；只决定完整组能否启动，不是硬存量上限，也不是性能保证 |

**新增配置项的三处同步**：记录分量、编解码的可选字段、默认值实例必须同时更新，否则解码失败并整体回退默认。

## 9. 扩展点与踩坑

| 要做什么 | 落点 | 踩坑 |
|---|---|---|
| 新增平台能力 | 扩展平台能力契约 + 两端实现 | 内核经统一入口使用，不要让内核 import 平台类 |
| 新增"内核需要平台状态"的能力 | 优先扩展窄接口或注入点 | 窄接口返回值可能为空 |
| 新增"服务端主动触达客户端" | 静态 sink 模式 | 不要由内核引用客户端 |
| 必须新增 Mixin | 仅在无等价事件时 | 只作入口；业务放内核；两端描述符各自维护 |
| 新增平台事件 | 两端事件转发类 | 业务留在内核；tick 只推进一次 |
