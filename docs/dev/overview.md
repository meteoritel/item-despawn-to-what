# 项目概述

> 本文是抽象层文档的起点，只交代项目定位、边界与术语，不涉及类与方法。
> 架构与模块分层见 [architecture.md](architecture.md)；术语进入代码前的读法见 [conventions.md](conventions.md)。

## 1. 一句话定位

ItemDespawnToWhat（mod id `itemdespawntowhat`）是一个 Minecraft 1.21.1 的 Fabric / NeoForge 双端服务端模组：
让**即将自然消失**、或被**火 / 岩浆 / 仙人掌销毁**的掉落物，按声明式**规则**转化为其他物品、实体、方块、经验或世界效果。

模组的核心不是"硬编码若干转化"，而是提供一套**规则引擎 + 规则编辑能力**：
规则可来自数据包与 config，可在游戏内通过独占编辑会话用图形界面维护，也可直接用命令与 JSON 管理。

| 项 | 取值 |

| 规则命名空间 | 内置与默认覆盖层使用 `itemdespawntowhat`，第三方类型与规则可使用自有命名空间 |

## 3. 系统边界

**系统提供的**：规则的数据形态与校验、三层规则来源、规则执行运行时（追踪 / 排期 / 条件求值 / 完整组结算）、
规则编辑协议与图形编辑器、命令入口、开发环境调试场景与性能观测。

**系统当前明确不提供的**（避免把边界当缺陷）：

- 不自动迁移旧版本配置：旧格式一律**明确报错、不静默兼容**，历史迁移命令已退役。
- 不为规则执行**主动加载区块**；区块不可用时退避重试，不生成新区块。
- 条件求值**不修改世界**：副作用只发生在效果执行阶段。
- 不提供跨加载器统一的 Mixin 方案：两端各自使用各自的原生事件与最小 Mixin。
- 不提供图形编辑器以外的规则配置入口保证：命令与 JSON 是稳定入口，但界面承担主要交互。

## 4. 领域术语

| 术语 | 含义 |
|---|---|
| 规则（rule） | 后端唯一的配置单元：声明一类源物品在某种触发方式下产生哪些结果 |
| 源物品（source） | 被规则匹配的掉落物；匹配支持物品 id 与物品标签，并支持排除项 |
| 消失方式 / 触发原因（trigger） | 规则声明的触发时机：自然消失、火、岩浆、仙人掌；未声明时按自然消失 |
| 条件树（condition tree） | 规则级或效果级的递归条件表达式，由组合节点、取反节点与条件叶构成 |
| 条件叶（condition leaf） | 一个原子条件（如维度、群系、时间、周围方块、催化剂存在等） |
| 效果（effect） | 一次世界操作或一次消耗声明（生成物品 / 实体 / 经验、放块、开战利品表、闪电、爆炸、箭雨、天气、消耗源 / 催化剂 / 流体） |
| 候选结果 / 方案（outcome） | 一组共同执行的效果；一条规则可有多个候选，按组合模式选定其中一个 |
| 固定成本 | 规则级声明的**每组**消耗：源物品消耗 `source_cost` 与催化剂消耗 `catalyst_cost` |
| 催化剂（catalyst） | 转化发生时按引用支付、作为"条件 + 成本"双重角色的物品 |
| 门槛（threshold） | 催化剂存在条件要求达到的数量；可显式声明，也可留空由运行投影解析 |
| 完整组（complete group） | 结算的最小单位：一组内多个效果共同执行，成本按组支付 |
| 结算（settlement） | 把整堆源物品转入结算库存，按组规划、派发、交付的推进过程 |
| 返还（return） | 未组成完整组或执行后剩余的源物品，作为新的掉落物交还世界 |
| 三层来源 | 内置数据包 < 世界数据包 < config 覆盖层（同 id 覆盖，层内后者胜） |
| 覆盖层（overlay） | config 下可写的规则目录，是编辑器与命令的写入目标 |
| 快照（snapshot） | 服务端下发给编辑器的规则来源三视图（base / overlay / effective）与问题清单 |
| 变更集（change set） | 编辑器上行提交的规则增删集合，带乐观并发基准版本 |
| 独占编辑会话 | 全局单一编辑目标下，同一时刻至多一个活跃会话；带租约与心跳 |
| 候选目录（catalog） | 供编辑器选择的注册表候选（物品 / 方块 / 实体 / 战利品表 / 群系 / 维度 / 标签 / 流体 / 状态效果） |
| 调度器与预算 | 全服共享一份每 tick 软预算与工作量上限的任务调度机制 |
| 掉落物状态 | 挂在实体层的新产物保护、转化冷却、返还物永久禁转等状态 |
