# Triage 标签

本地分诊任务的 `Status:` 使用以下映射。

| 规范角色 | 本地标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交给 Agent 实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予处理 |

技能提到分诊角色时，使用对应本地标签。
