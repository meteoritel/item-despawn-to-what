# ADR-0039：规则分类组的判定归属

- 状态：已实施。
- 相关决策：[ADR-0020](0020-source-catalog-and-overlay-control-entries.md)（来源目录与状态语义不变）；[ADR-0019](0019-exclusive-edit-session-and-target-lock.md)（协议版本化握手与回执状态码沿用）；[ADR-0040](0040-on-demand-snapshot-source-views.md)（快照条目结构与来源视图按需下发）。
- 术语：规则分类组见 [GLOSSARY.md](../../GLOSSARY.md)。

## 背景

规则管理页按「规则分类组」把条目分组展示。分类要同时满足：作者能表达「这条规则属于哪个特殊分组」的意图，客户端展示有稳定的层级、顺序与显示名，服务端、命令与后续消费方能不依赖界面拿到同一结果。若分类由客户端按效果类型字符串自行判定、层级另在列表页硬编码，两处没有共享模型，新增分类漏改任一侧会让归类中断整次列表刷新；分类语义也无法被服务端、命令或后续消费方复用。

## 决策

1. **规则可显式声明分类**：规则 JSON 顶层可选字段 `category`；作者手写值即分组意图，落盘后生效。字段可选，缺失时回落到分类器派生。
2. **装配层判定**：服务端装配快照时，从原始 JSON（overlay 优先于 base）读取显式值；缺失时由分类器按生效效果的产出类型派生；两者不一致时以显式值为准，不视为异常、不产生告警（手写值表达作者的分组意图）。
3. **分类器由类型元数据驱动**：`EffectType.productKind()` 声明产出类别（默认 `NONE`，表示非产出）；组合语义：单一产出类别直接归类，多个根类别为 `mixed`，entity 下多个子类别为 `entity.mixed`，无产出或含 `extension` 归 `extension`。
4. **运行时模型不感知分类**：`Rule` record 不承载 `category`，运行期解码与执行不读取它；分类只存在于原始 JSON、装配结果与快照条目。
5. **客户端只消费最终值**：快照条目携带装配后的分类；客户端静态模型维护已知分类的层级、顺序与显示名；未知分类按原文动态成组，不中断刷新，也不产生告警。
6. **GUI 编辑自动分配**：客户端编辑产出结构（增删效果、修改 `spawn_entity.variant`、调整效果顺序）时，按「感知默认值」策略写入内存草稿：当前分类为空或等于派生值时更新，手写特殊分组保持不变；写入作为可撤销编辑；复制规则不继承手写分类；保存落盘后该值成为显式值。
7. **单一分类**：一条规则只有一个分类；调试测试规则由生成器显式写入 `debug`，归类不按 id 前缀推断。
8. **「未完成」是客户端展示分组**：编辑器列表把当前有未保存改动（含本次新建）的条目归入 `unfinished` 分组。该分组只由客户端草稿状态决定，分类器不产出该值，编辑器也不会把它写进规则 JSON；草稿保存或撤销回原状后，条目按快照分类或兜底分组展示。
9. **「有问题」是客户端展示分组**：条目带服务端校验问题或客户端解码失败时归入 `issues` 分组，优先于「未完成」与快照分类；问题消失后条目回到自身分组。该分组同样不进入分类器与规则 JSON，分组无成员时在树上自动隐藏，玩家无需切换筛选即可看到新出现的问题。`template` 分组为发布前的模板规则预留。

## 考虑过的替代方案

- **客户端派生**：分类只服务客户端展示，但判定与骨架两处各自硬编码，缺一即中断列表刷新；服务端与命令无法复用。否决。
- **完全由服务端判定、客户端零输入**：分类无法表达作者的特殊分组意图（如 `debug`），复制与新建规则的分组也不可控。否决。
- **声明必填并严格校验**：手写拼写错误会让整条规则失效，展示性字段不应有这种破坏力；故声明可选、未知值按原文成组。否决。
- **分类进入 Rule 运行时模型**：模型被迫承载展示语义，所有构造点与校验都要带上它，运行时不使用，属于净负债。否决。
- **多分类（分类列表）**：同一规则会出现在多个分组，选中、计数与展开状态都要处理多归属。否决。

## 后果

- 快照条目携带分类字段，协议版本随之递增；列表页直接消费下发值。
- 分类器成为派生语义的唯一事实源；新增效果类型需声明 `productKind()`，未声明即视为非产出。
- 客户端需要维护「感知默认值」比较与复制清空逻辑；静态骨架需覆盖已知分类，并为未知分类保留按原文成组的兜底。
- 列表页分组顺序为「有问题」→「未完成」→ 快照分类 → 扩展兜底；前两个分组无成员时自动隐藏。
- 分类字段只影响展示与分组，不参与运行时匹配、结算或优先级。
