# ADR-0025：维护可复用客户端 kit，为独立 API 库准备边界

> 状态：已实施。

后端规则更新需要标量/区间/周期控件、目录网格与更完整的输入生命周期，而用户希望尽量复用并将 kit 未来独立为 API 库。继续维持 [ADR-0022](0022-client-ui-kit-adoption.md) 的冻结复制件、把新增能力全部放在业务 widget 中，会使交互和主题依赖继续混杂，之后拆库成本增加；立即发布外部库又会把尚在开发的接口过早固化。

决定将本仓库 kit 调整为**记录来源与差异的维护副本**：在明确输入、样式、事件和泛型数据边界后提取有实际用途的组件，宿主提供 Component、renderer、主题与业务适配。kit 保持 Minecraft 客户端通用依赖，不依赖本模组 core/edit/net/theme/widget、loader 或规则 JSON；规则命名、单位、目录协议、草稿与权限仍由宿主承担。

只替代 ADR-0022 关于永久机械改写与冻结副本的约束；同源来源、主题分层、平台隔离与来源可核查性继续成立。新增与修改只落在 kit 自身，不伪造原提交的内容，不修改来源项目。独立库的 package、坐标、版本、许可与发布另立任务；当前未在 `settings.gradle` 中拆出独立模块，也不以绝对路径依赖来源仓库。

后果：基础输入与生命周期统一到 kit，宿主 widget 只保留必要适配；公开接口需要示例和依赖审阅。接受这部分开发成本，换取后续复用与拆库时不携带规则业务；没有真实调用的抽象延后。

Kit 提取通用实体绘制核心与受控图标绘制适配，供目录、管理树、方案/行为行和选中预览等处复用；宿主提供实体创建、缓存/失效、模型中心/尺寸修正与项目指定的屏障图标/本地化提示。通用核心负责适框、旋转、裁剪、光照、缓冲提交和状态恢复，不接管目录协议或规则语义。渲染依赖白名单按实际使用精确放行原版 `com.mojang.blaze3d` 类（当前为 `platform.Lighting`、`vertex.PoseStack`、`vertex.VertexConsumer`），并同步检查脚本、package-info 与 API 文档；禁止项目业务、Gson 与 loader 反向依赖的边界继续有效，不整包放开 com.mojang，不以全限定名绕过约束。分层为 `UiEntityPreview` / `UiIcon.Rendered` / 宿主 `EntityPreviewIcons`，职责与依赖边界见 [UI kit 模块文档](../modules/ui-kit.md)。
