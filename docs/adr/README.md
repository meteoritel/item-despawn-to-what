# 架构决策记录（ADR）

> 本目录是项目的决策文档集：只回答「为什么这样设计、否决了哪些替代方案」。
> 实现事实见[开发者文档](../README.md)；领域术语见根目录 [GLOSSARY.md](../../GLOSSARY.md)。ADR 只链接，不复述实现细节。

## 编号与状态

- 编号是稳定标识，一经分配永不复用；本索引只登记当前有效的决策。
- 标题格式固定为 `# ADR-NNNN：<标题>`。
- 状态取值：**已接受**（决策有效）与**已实施**（决策有效且代码已落地）。
- 决策一旦被后续决策取代，由新的 ADR 承载现行决策，原决策移出本目录；本目录不保留历史注记，因此索引中的编号不连续，空出的编号不再复用。

## 维护规则

- 写作范围：背景、决策、考虑过的替代方案、后果；不写实现步骤、修改记录与日期追加段落。
- 引用只允许指向现行文档，链接必须可解析；禁止引用已不在仓库现行文档中的文档。
- 与其它文档的分工：五层开发者文档描述当前实现与契约，ADR 只解释取舍。
- 新增 ADR：取下一个未使用编号，按标题格式新建文件，并登记到下方索引。
