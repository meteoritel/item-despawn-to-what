# ADR-0059：目录类型决定名称解释

- 状态：已实施。

## 背景

内置目录的名称来源按类型固定。条目与已选内容需要一致的本地化和缺键显示，文本是否含句点无法准确区分翻译 key 与原文。

## 决策

目录类型在 CatalogTypePresentation 中明确解释名称：物品、方块、实体、状态效果与群系解释来源提供的翻译 key；战利品表使用原文；维度使用客户端维度名称规则；流体使用放置态方块名称；标签按 TaggedId 显示完整引用。副标题保持来源原文。缺少本地化时复用资源路径可读名称，技术 id 保留给搜索与悬停。

## 取舍

RuleCatalogEntry 与 payload 保持现有形状，类型策略承担已知来源的解释契约。逐条增加名称判别字段会扩大 wire 契约，却没有当前混合来源消费者；按字符形状猜测则会误解释带句点原文。名称策略同时服务目录和已选内容，使语言与资源变化只需失效客户端展示投影。
