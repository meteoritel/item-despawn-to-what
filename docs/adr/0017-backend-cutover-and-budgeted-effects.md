# ADR-0017：后端切换、预算化效果与前端占位

- 状态：已实施（2026-10-02）；构建/静态验证见收尾记录，游戏验收独立进行。
- 原因：后端审查 B01–B17；用户要求完成后端、弃用旧链路，前端下一步再重构。
- 替代范围：旧链路实现与前端冻结约束；补充 ADR-0012～0016 的调度、生命周期和保存细节。

> **前端部分已取代（2026-10-03）**：决策 2 的「前端占位屏」已被 P1–P8 前端重构取代——占位屏已删除，规则编辑器落地；前端决策见 [ADR-0018～0022](0018-condition-tree-contract.md) 与 [plan-frontend-rewrite-contract.md](../plan/plan-frontend-rewrite-contract.md)。本文其余后端决策仍现行。

## 决策

1. `core/**` 成为唯一执行链路。删除旧模型、IO、条件注册表、执行器、网络、命令、平台入口和两套未交付编辑器。用户磁盘旧 JSON 不删除；仅显式 convert 读取。
2. 前端保留本地化占位屏、快捷键、打开屏幕 payload；保留服务端编辑协议。下一轮前端从协议建立模型，不依赖已删除 DTO。
3. 每条候选单独核对实际年龄，source.exclude 始终生效。自然消失前保留预算内最终检查；仅玩家死亡掉落锁定。源实体一旦提交转化，持久化实体标签防止再次提交。
4. 检查与效果采用独立、可取消、支持逾期与零延迟的分桶队列。大量世界操作分批；列表顺序保证启动顺序，后续批次可交错，不保证前一个效果完整结束再开始下一个。
5. 维度状态包含任务、标签和气候缓存，可以持有 ServerLevel 引用；在维度卸载/停服整体释放。区块卸载保留效果，重载保留已提交效果，重启不持久化。
6. 延迟效果保存源物品快照，在已加载目标区块操作，不强制加载。单次原版原子操作无法被软预算抢占，爆炸威力上限 16。
7. 加载与提交都走 Codec、类型、语义与动态引用校验；拒绝部分解码结果。关键目录/资源枚举失败时重载保留旧索引。NeoForge 重载在新资源、标签绑定之后执行。
8. 类型扩展使用 `core.extension.RuleTypeProvider` + Java ServiceLoader。先条件注册并冻结，再建立表达式 Codec，最后效果注册并冻结。重复 id 与 provider 错误启动即失败。
9. 保存整批预备、备份、提交；普通 I/O 失败尝试回滚，多文件进程崩溃事务不在范围内。编辑版本涵盖 reload/convert/save，请求/保存核对磁盘原始字节修订。
10. convert 备份成功才转换，id 含旧文件相对路径，重复转换保留已有规则；无法安全映射的 v1 或第三方条件显式报告。

## 后果与验收

性能取舍保留可观测队列预算、分批与有界缓存，同时明确单次爆炸/查询/战利品不能抢占。consume 与产出不提供事务预检或全局硬额度；方块上限为作业开始的局部额度。游戏行为与 1 万掉落物性能仍需用户分别在 Fabric、NeoForge 实测。

当前实现与逐项验收步骤以[收尾记录](../review/backend-rewrite-closeout-2026-10-02.md)为准。规划书与早期 ADR 保留为历史决策依据。
