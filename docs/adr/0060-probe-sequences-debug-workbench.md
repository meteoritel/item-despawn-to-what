# ADR-0060：探针统一序列与开发调试工作台

- 状态：已实施；当前入口见 [后端探针](../guides/backend-probes.md)、[GUI 探针](../guides/gui-probes.md)。

## 背景

命令流水线与隔离进程需要使用相同场景、性能门禁和终态，同时保留玩家生命周期、独立存档与跨进程恢复的差异。前端需要同时展示多个真实组件，并从统一入口进入不同工具。

## 决策

1. 开发资源中的统一序列目录描述 scene、bench、world 步骤及重启阶段。共享运行器拥有步骤推进、deadline、冷却、清理与结果；命令和隔离进程只承担宿主职责。单场景也经同一运行器进入。
2. 世界与文件控制留在开发夹具，生产 RuntimeObserver 继续承担 [ADR-0035](0035-runtime-observation-seam.md) 的观测与故障注入职责。账本恢复使用开发源集同包夹具与真实存档重启。
3. 调试工作台以独立开发 Screen 持有工具目录和本地场景。正式客户端只提供打开动作接缝；草稿工具仍由编辑器拥有，返回时按有效工作区重建屏幕，沿用 [ADR-0048](0048-editor-shell-owns-editing-state-and-active-page.md) 的外壳所有权。
4. 组件与模态沿用 [ADR-0055](0055-ui-input-scope-ownership.md) 的输入作用域。GUI 用例声明目标、动作和命名断言，选择器读取实际层级与裁剪区；运行记录持有判定及原始证据，HTML 与拼图消费投影。

## 取舍与后果

显式目录和工具工厂覆盖当前扩展需求；新增场景和工具接入所属目录。Java、Python 与 JavaScript 各自持有运行、驱动和客户端输入职责。开发代码由 NeoForge probe 装配，正式双平台包继续执行隔离检查。
