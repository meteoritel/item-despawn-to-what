# ADR-0046：安全生成按危险度评分选址

- 状态：已实施。

## 背景

安全生成原先只接受同时满足全部硬条件的落点：范围内没有伤害方块、下方可落脚、符合该实体原版放置要求。狭窄地形里（熔岩池上方的窄台、洞穴顶、仙人掌与甜浆果丛夹缝）整片候选往往各有一项不满足，产出与源成本同时消失；把落点从「合格/不合格」二元判断改为可比较的分数，才能在同一片候选里挑出伤害最轻的一个。

## 决策

候选落点按危险度打分，0 分表示完全安全，分数越高越危险。越界、低于世界最低高度、生成碰撞箱与方块相交、脚下方探测不到可落脚方块这四类属于不可生成，直接跳过；伤害方块按严重度累加，悬空高度按脚下着落距离加罚，不符合原版放置要求只记一份轻罚。搜索仍按离触发点由近到远进行，每刻检查数受 `position_search_checks_per_tick` 约束并跨刻续接，每个候选在整次交付内最多判定一次。

选择规则是：遍历中遇到 0 分候选立即命中；剩余候选都带危险时，每个实体取剩余候选里危险度最低的一个生成；只有剩余候选都不可生成时才按失败处理。失败时一个实体都没生成则本组源成本原路退回，已生成部分按真实产出收尾。命中分值与是否来自危险度回退随 `SPAWN_POS_SEARCH` 观测事件上报，便于区分安全命中与回退命中。行为细节见[候选结果与结算](../wiki/zh-05-outcomes-and-settlement.md)，结算侧退款见[转化运行时](../modules/conversion-runtime.md)。

## 考虑过的替代方案

- 保留硬筛并扩大搜索范围：失败集中在附近本就危险的地形，扩大范围只会增加每刻候选数，不改变「整片都不合格就失败」的结论。
- 命中最低分候选后立即生成：最低分要比较完整片候选才能确定，提前命中可能错过后面完全安全的落点。
- 只挑最近的可用落点：距离近不代表伤害轻，等于把危险落点与安全落点当作同等选项。
- 给产物附加落点状态标记：需要把新状态扩散到实体层与存档，且无法在生成前表达「更危险 / 更安全」的选择关系。

## 后果

危险地形里转化仍能产出，落点可能带伤害或悬空；退款只发生在剩余候选都不可生成时。观测事件同时给出命中危险度与回退标记，排查时可以分辨常规命中与退让命中。评分权重按严重度集中在一处定义，调整伤害种类的相对轻重不改选择规则。
