# ADR-0028：条件树画布页、扁平皮肤与 kit 公开面扩张

- 状态：已实施；公开面见 [UI kit 模块文档](../modules/ui-kit.md)。
- 依据：条件树编辑页的实机反馈，以及 [ADR-0022](0022-client-ui-kit-adoption.md)、[ADR-0025](0025-reusable-client-ui-kit-boundary.md)。

## 背景

条件树编辑页原本是「缩进行 + 参数侧栏 + 两排按钮」：结构层级不清、参数区常驻占屏、工具入口拥挤。规则作者要求把它换成整页画布式节点图编辑器。同时出现两处既有决策与现状不符：ADR-0022 决策 6 要求「禁止现代网页式圆角卡片」，而 `UiTheme.drawCard` 已使用圆角九宫格贴图；ADR-0022 与 ADR-0025 要求 kit 作为可与源提交逐文件比对的维护副本，而画布所需的树布局、点阵网格、正交连线、框选、图标图集切片、图标条与浮动面板不在 kit 公开面内，画布页只能自带一套几何与交互。

## 决策

1. **视觉双轨制**：窗口、面板与内凹区保留灰色像素凸凹；卡片、列表行、按钮与分段控件使用九宫格底图。「禁止现代网页式圆角卡片」不再作为验收基线。
2. **扁平皮肤限定作用域**：画布页外壳（功能栏、工具列、画布边框、帮助与状态行）与内联参数编辑框使用扁平皮肤（1 像素同色描边 + 灰阶层次、无立体凸凹与阴影）；扁平主题只经 `UiHostThemes.flatTheme()` 显式取用才生效，其它编辑页仍用默认像素主题。
3. **画布页不做折叠**：始终展示整棵树，节点位置由结构决定；视图状态只有平移与整数档缩放。
4. **通用能力进 kit**：树布局、点阵网格、正交连线、框选、图标图集切片、图标条与浮动面板落在 kit 公开面；本模组专属控件留在宿主控件层。kit 不得反向依赖宿主包，边界继续由脚本强制。
5. **kit 定位修正**：从「可与源提交逐文件比对的复制件」改为「记录来源与差异的维护副本」——新增与修改在 UI kit 文档登记，而不是靠与上游逐文件比对。

## 考虑过的替代方案

- **只给画布页做皮肤、kit 保持只读**：画布原语会被迫写进宿主控件层，无法复用，也与「通用能力并入 kit」的要求冲突。
- **全量扁平化所有编辑页**：受影响面覆盖全部表单页，风险与本次目标不成比例；双轨制把改动限制在画布页。
- **保留常驻参数侧栏**：实机反馈明确要求「太占空间」，改为选中条件叶后就地展开编辑框。
- **继续要求逐文件比对**：任何通用能力扩张都会让复制件与上游必然分叉，该约定无法长期成立。

## 后果

- ADR-0022 决策 6 的圆角卡片禁令由本决策取代；kit 的公开面与差异记录方式见 [UI kit 模块文档](../modules/ui-kit.md)。
- 画布页与表单页各自维护一套视觉规格；页面职责、四页界面契约与表单/叶面板分工见[客户端 UI 模块文档](../modules/client-ui.md)。
- 新增 kit 公开类需要登记，`tools/check-ui-kit-boundaries.ps1` 仍是唯一强制校验。
