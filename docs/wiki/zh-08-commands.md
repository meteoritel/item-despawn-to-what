# 命令参考（/idtw）

> 适用版本：**2.0.0**（Minecraft **1.21.1**）。

输入 `/idtw` 可以在聊天栏中查看当前身份可用的命令列表。所有命令均支持 Tab 键自动补全。

---

## 常用命令速查表

| 命令 | 用途简述 | 执行权限要求 |
| --- | --- | --- |
| `/idtw` | 显示模组帮助与可用命令入口 | 所有人 |
| `/idtw editor`（或 `/idtw editor open`） | 打开游戏内可视化规则编辑器 | 管理员（单人房主或权限 ≥2） |
| `/idtw editor status` | 查看当前编辑器是否被其他玩家占用 | 所有人 |
| `/idtw editor release` | 强制释放被占用的编辑器会话 | 管理员（权限 ≥2） |
| `/idtw rule list [页码] [关键词]` | 分页浏览已生效的全部规则 | 管理员 |
| `/idtw rule show <id>` | 查看指定规则的详细信息与摘要 | 管理员 |
| `/idtw rule show <id> raw [页码]` | 分页查看指定规则在磁盘上的原始 JSON | 管理员 |
| `/idtw rule validate [页码]` | 校验规则文件是否有语法错误或非法参数 | 管理员 |
| `/idtw rule reload` | 重新读取磁盘规则并立即应用到游戏中 | 管理员 |
| `/idtw rule enable <id>` | 在当前存档中强制开启某条规则 | 管理员 |
| `/idtw rule disable <id>` | 在当前存档中强制停用某条规则 | 管理员 |
| `/idtw rule reset <id>` | 清除当前存档的设置，恢复规则默认开关 | 管理员 |
| `/idtw rule orphans [页码]` | 检查已被删除的残留规则启停记录 | 管理员 |
| `/idtw rule orphans clear` | 清理已被删除的残留规则记录 | 管理员 |

> **权限说明**：在单人游戏中，存档拥有者自动拥有全部管理权限；在多人服务器中，管理命令要求 OP 权限（权限等级 ≥2）。

## 1. 规则编辑器命令

### `/idtw editor` 或 `/idtw editor open`
- **作用**：打开游戏内可视化规则编辑器。
- **独占机制**：为防止多位管理员同时修改造成冲突，编辑器采用**独占会话机制**，同一时间只允许一位玩家编辑。
- **遇到占用时**：如果界面提示被占用，可联系持有者关闭界面，或使用下面的释放命令。

### `/idtw editor status`
- **作用**：查看当前是否有玩家正在使用编辑器。
- **回显**：显示当前会话状态（如「等待打开」、「正在编辑」）以及占用者的玩家名称。

### `/idtw editor release`
- **作用**：强制关闭并释放被占用的编辑器会话。
- **场景**：当持有者玩家离开电脑或意外卡住时，管理员可执行此命令将其释放，以便他人打开。

---

## 2. 规则查看与排查

### `/idtw rule list [页码] [关键词]`
- **作用**：分页列出当前游戏中生效的所有规则（每页 8 条）。
- **用法示例**：
  - `/idtw rule list`：查看第 1 页规则；
  - `/idtw rule list 2`：翻到第 2 页；
  - `/idtw rule list 1 diamond`：搜索包含 `"diamond"` 的规则并显示第 1 页。
- **便捷交互**：鼠标悬停在列表行上可查看规则来源；直接点击某一行，会自动将 `/idtw rule show <id>` 填入你的聊天输入框。

### `/idtw rule show <id>`
- **作用**：在聊天栏输出指定规则的完整摘要信息。
- **包含内容**：规则名称、来源层（数据包或覆盖层）、启用状态、优先级、消失触发方式、触发等待时间以及产物效果统计。

### `/idtw rule show <id> raw [页码]`
- **作用**：直接读取并展示磁盘上的原始 JSON 配置内容。
- **说明**：内容会自动分段分页展示，方便复制与比对。

---

## 3. 规则校验与应用

### `/idtw rule validate [页码]`
- **作用**：扫描全部规则文件，检测是否存在语法错误、拼写失误或越界参数，但不改变游戏内运行的规则。
- **回显反馈**：
  - 若全部正确，显示「校验通过」；
  - 若有错误（如未知物品 ID、非法字符），会分页标红列出具体出问题的文件与字段路径，方便快速定位修复。

### `/idtw rule reload`
- **作用**：重新读取磁盘上的所有规则文件，让新修改立即在游戏中生效，并自动刷新当前世界中存活的掉落物。
- **容错保护**：如果个别规则存在错误，模组只会拒载有问题的单条规则，其余正确的规则照常生效并给出清晰提示。

---

## 4. 本存档独立启停与清理

### `/idtw rule enable <id>` 与 `/idtw rule disable <id>`
- **作用**：针对当前存档独立开启或禁用某条规则。
- **存档隔离**：该修改仅记录在当前世界的存档数据中，不会改动磁盘上的 JSON 文件。即使规则文件里写了 `"enabled": false`，执行 `enable` 后在该存档依然会生效。

### `/idtw rule reset <id>`
- **作用**：清除当前存档对该规则的独立设置，让规则重新跟随自身 JSON 文件中的 `enabled` 默认值。

### `/idtw rule orphans` 与 `/idtw rule orphans clear`
- **作用**：如果你曾用命令启停过某条规则，后来又在磁盘上彻底删除了该规则文件，存档中会残留对应的孤儿启停记录。执行 `clear` 可一键清理这些无用的残留记录。
