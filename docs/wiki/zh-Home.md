# ItemDespawnToWhat 玩家指南

> 适用版本：**2.0.0**（Minecraft **1.21.1**）。

2.0.0 不附带内置规则数据包。首次使用时，请通过游戏内编辑器创建规则，或添加自己的规则 JSON、世界数据包。

## 创建第一条规则

1. 安装模组并进入世界；多人游戏中，服务器和使用编辑器的玩家客户端都需安装模组。
2. 在聊天栏执行 `/idtw editor open`，也可使用 `/idtw editor`。
3. 点击「新建规则」，设置输入物品、触发时机、条件和结果。
4. 点击底部的「应用更改」，等待保存成功；规则会自动重载并生效。

已有规则可以复制后修改。列表中的本服开关按存档启停规则；「默认启用」决定没有本服设置时的状态，「恢复默认」让本存档重新跟随默认值。字段和按钮的用途可通过悬停提示查看。

**权限与占用**：单人存档房主可直接使用；其他玩家需要权限等级 ≥2。同一时间只允许一个人编辑，遇到占用提示时，等对方关闭编辑器，或由管理员执行 `/idtw editor release` 释放会话。

按图创建第一条规则，见[首次使用与生效流程](zh-01-getting-started)。教程从 GUI 操作开始，也提供手动编写 JSON 的示例、文件位置与生效步骤。
