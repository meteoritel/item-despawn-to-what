# ItemDespawnToWhat 玩家指南

装上模组、进入世界，输入 `/idtw config edit` 就能打开配置编辑器。**想先体验这个模组，直接打开它、照着界面上的提示走一遍就够了**；下面其余内容只是需要查资料时的索引。

## 先打开游戏内的编辑器

1. 进入一个世界。
2. 输入 `/idtw config edit` 并回车。
3. 在规则列表里选中一条，点「编辑」，就能在「基本 / 输入 / 触发 / 结果」四个页签里改它能变出什么、什么情况下才变。

编辑器里自带示例规则，不用先写任何文件就能玩起来：

- 「新建规则」从零做一条；
- 「复制」照着示例改一条；
- 列表里的「启用 / 停用」按本存档切换它参不参与；
- 基本信息分区的「默认启用」是规则自身的默认状态，「恢复默认」把本存档的设置退回它；
- 改完点「保存」，改动立刻生效。

不知道某个字段或按钮是做什么的，把鼠标停在上面看提示即可。

**权限与占用**：单人世界直接可用；多人服务器需要管理员（权限等级 2）。同一时间只允许一个人编辑，提示已被别人锁定时，等对方关闭编辑器，或让管理员执行 `/idtw config edit-lock release` 释放。

想改用文件写规则，看 [首次使用与生效流程](zh-01-getting-started)：那里有一条照抄就能用的最小规则，也有文件位置与生效步骤。
