# ItemDespawnToWhat 玩家配置指南

这一页是全部玩家文档的入口：它说明每篇文档解决什么问题，并给出按使用目的查找的路径。

只想让某个掉落物变成别的东西，直接读 [首次使用与生效流程](zh-01-getting-started)：那篇有一条可以直接抄的最小规则，以及文件放哪、怎么让它生效的完整流程。其余需求按下表查找。

## 建议阅读顺序

| 阶段 | 读什么 | 你会拿到 |
| --- | --- | --- |
| 第一次使用 | [首次使用与生效流程](zh-01-getting-started) | 一条能跑起来的规则，以及确认它已生效的方法 |
| 摸清能配哪些字段 | [规则基础字段](zh-02-rule-basics) | 认哪些掉落物、何时触发、开关与优先级 |
| 加条件、改结果 | [条件](zh-03-conditions)、[效果](zh-04-effects) | 什么情况下才转化，以及转化出什么 |
| 多结果与代价 | [候选结果与结算](zh-05-outcomes-and-settlement) | 多个产出怎么轮询、每组付多少、没转化成的东西去哪了 |
| 覆盖、调优、查状态 | [来源层与覆盖](zh-06-layers-and-overrides)、[服务端配置](zh-07-server-config)、[命令参考](zh-08-commands) | 覆盖内置规则、调整转化节奏、读懂命令输出 |

## 文档目录

| 页面 | 你会在这里看到什么 |
| --- | --- |
| [首次使用与生效流程](zh-01-getting-started) | 这个模组做什么、配置文件放在哪、一条最小可用规则，以及让规则生效的流程与不生效时的排查清单。 |
| [规则基础字段](zh-02-rule-basics) | 一条规则顶层能写哪些字段，每个字段的作用、取值与默认值，以及什么时候需要动它。 |
| [条件](zh-03-conditions) | `conditions` 怎么写：条件树由哪些节点组成、10 个条件类型各有哪些参数，以及条件不满足或判定不了时会发生什么。 |
| [效果](zh-04-effects) | 规则命中后能做什么：10 种效果类型各自的 `type` 与参数，以及你在游戏里能看到什么。 |
| [候选结果与结算](zh-05-outcomes-and-settlement) | `effects` 与 `outcomes` 两种写法、多个结果之间的轮询、每组的固定成本与消耗，以及整组怎么扣怎么返还。 |
| [来源层与覆盖](zh-06-layers-and-overrides) | 三层来源的优先级、用同 id 规则整条替换、停用或删除内置规则，以及多条规则抢同一个掉落物时听谁的。 |
| [服务端配置](zh-07-server-config) | `server.json` 每一项在管什么、默认值是多少，以及卡顿或转化节奏不对时该改哪里。 |
| [命令参考](zh-08-commands) | 全部命令、它们要求的权限，以及输出该怎么读。 |

## 一页速查

| 我想…… | 去看 |
| --- | --- |
| 写下第一条规则（例如鸡肉 10 秒后变腐肉） | [首次使用与生效流程](zh-01-getting-started) |
| 改掉落物会变成什么（物品、生物、方块、经验、天气） | [效果](zh-04-effects) |
| 只在特定情况下才转化（维度、生物群系、时间、天气、高度、光照……） | [条件](zh-03-conditions) |
| 改多久之后触发，或在火、岩浆、仙人掌销毁时触发 | [规则基础字段](zh-02-rule-basics) |
| 让某条规则优先于其它规则 | [规则基础字段](zh-02-rule-basics) |
| 停用或删除内置示例规则 | [来源层与覆盖](zh-06-layers-and-overrides) |
| 一个物品轮询产出不同东西，或给转化加上代价 | [候选结果与结算](zh-05-outcomes-and-settlement) |
| 服务器卡顿、转化太频繁、产物堆太多 | [服务端配置](zh-07-server-config) |
| 规则改完没生效，或不知道问题行怎么读 | [首次使用与生效流程](zh-01-getting-started)、[命令参考](zh-08-commands) |
| 想在游戏里编辑规则 | 运行 `/idtw config edit`，细节见 [命令参考](zh-08-commands) |

想了解实现原理与架构，见开发者文档 `docs/dev/`。
