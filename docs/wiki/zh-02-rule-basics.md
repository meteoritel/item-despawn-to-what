# 规则基础字段

> 适用版本：**2.0.0**（Minecraft **1.21.1**）。

本页介绍一条规则顶层可以配置的所有基础字段。无论是使用游戏内编辑器还是手写 JSON 规则，都可以参考本指南。

---

## 字段速查总览

| 字段名 | 作用与含义 | 取值范围 | 默认值 | 影响转化逻辑？ |
| --- | --- | --- | --- | --- |
| `id` | 规则唯一标识符 | `命名空间:名称` 字符串 | 单规则文件可由路径自动推导 | 是（同 ID 会覆盖） |
| `display_name` | 规则名称（用于游戏内展示） | 字符串（不超过 128 字符） | 省略时自动生成简要描述 | 否，仅影响界面显示 |
| `notes` | 规则备注说明 | 任意字符串（支持换行） | 无 | 否，仅用于自己记录 |
| `enabled` | 规则默认是否启用 | `true` / `false` | `true` | 是 |
| `priority` | 规则匹配优先级（抢占同个物品） | 整数（可为正、负或 0） | `0` | 是（数值越大越先尝试） |
| `source` | 监听哪些掉落物 | 对象，`items` 为非空列表 | **必填** | 是 |
| `triggers` | 监听的消失方式列表 | `natural` / `fire` / `lava` / `cactus` | 默认为 `["natural"]` | 是 |
| `trigger_after_seconds` | 自然消失前的触发等待秒数 | 非负整数（秒） | `300` | 是 |
| `schema_version` | 规则格式版本 | 固定正整数 `1` | `1`（日常可省略） | 是 |

*注：转化的产物与消耗成本（`effects`、`outcomes`、`source_cost`、`combination` 等）请查阅 [候选结果与结算](zh-05-outcomes-and-settlement)。*

## 核心字段详解

### 1. id：规则的唯一身份证

- **作用**：唯一区分每条规则。游戏内指令、GUI 编辑器和日志报错都使用 ID 定位规则。如果两个来源提供了相同 ID 的规则，高优先级的来源将**整条替换**低优先级的规则（详见 [来源层与覆盖](zh-06-layers-and-overrides)）。
- **格式要求**：`命名空间:路径`，例如 `myrules:chicken_to_rotten_flesh`。只允许使用小写英文字母、数字、下划线、点或连字符，中间用冒号分隔。
- **自动推导**：如果一个 `.json` 文件中仅包含一条规则，你可以省略 `id` 字段，模组会根据文件相对于规则目录的路径自动推导 ID。多条规则数组必须显式指定 `id`。

### 2. display_name 与 notes：界面展示与备忘

- **`display_name`**：给玩家或服主阅读的友好名称，显示在编辑器列表和命令输出中。例如 `"自制：腐化鸡肉"`。
- **`notes`**：随手记录的备注信息（例如配置灵感、与哪个模组联动等），完全不影响实际游戏逻辑。

```json
{
  "id": "myrules:chicken_to_rotten_flesh",
  "display_name": "鸡肉腐化",
  "notes": "掉落在地上的生鸡肉会在 10 秒后变成腐肉。",
  "source": { "items": ["minecraft:chicken"] }
}
```

### 3. enabled：默认启用开关

- **作用**：决定这条规则是否默认参与匹配。
- **取值**：`true`（默认生效）或 `false`（规则仍会被读取并在列表可见，但不会触发转化）。
- **存档覆盖**：在单人存档或服务器中，管理员可以通过 `/idtw rule enable|disable <id>` 独立启停某条规则，存档设置优先于文件里的 `enabled`（详见 [来源层与覆盖](zh-06-layers-and-overrides)）。

### 4. source：匹配哪些掉落物

- **作用**：定义该规则针对哪种地面物品生效。
- **格式**：包含 `items`（必填，非空数组）和 `exclude`（可选数组）。支持单个物品 ID 与 `#` 开头的物品标签，两者总数最多 256 项。

| 写法示例 | 含义说明 |
| --- | --- |
| `"minecraft:oak_sapling"` | 精准匹配特定物品（仅橡树树苗） |
| `"#minecraft:saplings"` | 标签匹配：匹配该标签下的**所有树苗**（包含其他模组加入的符合标签的树苗） |

#### 使用 `exclude` 排除特例

`exclude` 的优先级高于 `items`。当使用物品标签大范围匹配时，可以用 `exclude` 挖掉不想被转化的物品：

```json
{
  "id": "myrules:saplings_plant",
  "source": {
    "items": ["#minecraft:saplings"],
    "exclude": ["minecraft:oak_sapling"]
  }
}
```
*上例表示：匹配所有树苗，但**排除**橡树树苗。*

### 5. priority：多规则冲突时谁先触发

- **作用**：如果同一个掉落物同时符合多条规则的匹配条件，**优先级（priority）数值最大的规则优先执行**。
- **取值**：支持任意整数（例如 `10`、`0`、`-5`），默认值为 `0`。
- **使用建议**：为带有严苛限制的特殊规则设置更高的优先级（如 `10`），为普通规则保持默认值 `0`，为兜底规则设置负数（如 `-10`）。

### 6. triggers：在哪些消失时机触发

- **作用**：声明物品在何种销毁途径下启动转化。
- **可选值**：数组格式，支持 `natural`、`fire`、`lava`、`cactus`，可同时多选。默认省略时等价于 `["natural"]`。

| 触发方式 | 触发时机与机制 | 是否等待计时器 |
| --- | --- | --- |
| `natural` | 物品存活时间到达 `trigger_after_seconds` 或自然寿命上限时 | **需要等待**设定秒数 |
| `fire` | 物品接触火焰被烧毁的瞬间 | **立即触发**，不等计时器 |
| `lava` | 物品接触岩浆被融化的瞬间 | **立即触发**，不等计时器 |
| `cactus` | 物品碰到仙人掌被刺破的瞬间 | **立即触发**，不等计时器 |

```json
{
  "id": "myrules:arrow_in_fire",
  "source": { "items": ["minecraft:arrow"] },
  "triggers": ["fire", "lava"]
}
```
*上例表示：掉在地上的箭自然消失时不会反应；只有被火烧或扔进岩浆时，才会在销毁瞬间立刻触发！*

### 7. trigger_after_seconds：自然消失等待时长

- **作用**：针对 `natural` 方式，物品掉落在地上存活多少秒后尝试触发。
- **取值**：非负整数（单位为秒），默认值为 `300`（5 分钟，与原版掉落物自然消失时间对齐）。
- **说明**：
  - 填 `10` 表示掉落 10 秒后触发；
  - 填 `0` 表示落地后立即开始尝试触发；
  - 如果填写的秒数超过了物品的自然存活时间，物品会在即将自然消失的一刻触发。

## 基础字段完整示例

下面是一份包含了所有常用基础字段的完整规则配置：

```json
{
  "id": "myrules:sapling_planting",
  "display_name": "树苗自动落地扎根",
  "notes": "除橡树苗外，所有树苗在掉落 60 秒后或被火烧毁时自动种下方块。",
  "enabled": true,
  "priority": 5,
  "schema_version": 1,
  "source": {
    "items": ["#minecraft:saplings"],
    "exclude": ["minecraft:oak_sapling"]
  },
  "triggers": ["natural", "fire"],
  "trigger_after_seconds": 60,
  "effects": [
    {
      "type": "idtw:place_block",
      "use_source_block": true,
      "shape": "square",
      "count": 1,
      "radius": 1
    }
  ]
}
```

## 配置校验与避坑指南

模组内置了严格的配置校验系统，格式错误的规则会被拒绝加载（拒载），确保游戏不会闪退。你可以随时执行 `/idtw rule validate` 检查规则：

| 常见错误原因 | 表现结果 | 正确做法 |
| --- | --- | --- |
| `id` 含有大写字母或空格 | 规则拒载，提示非法 ID | 仅使用小写字母、数字、下划线与冒号 |
| 物品 ID 拼写错误（如原版不存在此物品） | 规则拒载，提示未知源物品 | 仔细核对物品英文注册名或命名空间 |
| 标签名前面漏掉了 `#` | 模组会将其当成普通物品名处理并拒载 | 标签必须以 `#` 开头，如 `"#minecraft:logs"` |
| `enabled` 填成了字符串 `"true"` | 规则拒载，提示类型不匹配 | 填布尔值 `true` 或 `false`，不加双引号 |
| `trigger_after_seconds` 填成了负数 | 规则拒载，提示参数超出范围 | 填写 `0` 或正整数 |
