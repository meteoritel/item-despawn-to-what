# ItemDespawnToWhat 玩家配置指南

这一份索引是面向玩家的 **JSON 配置操作指南**：只讲配置文件里能写什么、怎么写、写完会发生什么。它不是开发者文档——想看实现与架构，请去 `docs/dev/`。

## 只想看结果？先读这一篇

如果你唯一的目的是「让某个掉落物变成别的东西」，读完 [首次使用与生效流程](01-getting-started.md) 就够了：那里有一条可以直接抄的最小规则，以及「文件放哪、怎么让它生效」的完整流程。

## 建议阅读顺序

| 阶段 | 读什么 | 你会拿到 |
| --- | --- | --- |
| 第一次使用 | [01 首次使用与生效流程](01-getting-started.md) | 一条能跑起来的规则 + 确认它已生效的方法 |
| 摸清能配哪些字段 | [02 规则基础字段](02-rule-basics.md) | 认哪些掉落物、何时触发、开关与优先级 |
| 加条件 / 改结果 | [03 条件](03-conditions.md)、[04 效果](04-effects.md) | 「什么情况下才转化」与「转化出什么」 |
| 多结果与代价 | [05 候选结果与结算](05-outcomes-and-settlement.md) | 多个产出怎么轮换、每组付多少、没转化成的东西去哪了 |
| 覆盖 / 调优 / 查状态 | [06 来源层与覆盖](06-layers-and-overrides.md)、[07 服务端配置](07-server-config.md)、[08 命令参考](08-commands.md) | 覆盖内置规则、调性能、读懂命令回显 |

## 文档目录

- [01 首次使用与生效流程](01-getting-started.md)：这个模组做什么、配置文件放在哪、一条最小可用规则，以及让规则生效的流程与不生效时的排查清单。
- [02 规则基础字段](02-rule-basics.md)：一条规则顶层能写哪些字段，每个字段的作用、取值、默认值，以及什么时候需要动它。
- [03 条件（conditions）](03-conditions.md)：`conditions` 怎么写——条件树由哪些节点组成、10 个条件类型各有哪些参数、条件不满足或判定不了时会发生什么。
- [04 效果（执行行为）](04-effects.md)：规则命中后能做什么——10 种效果类型各自的 `type`、参数，以及玩家会看到的现象。
- [05 候选结果与结算（outcomes）](05-outcomes-and-settlement.md)：`effects` 与 `outcomes` 两种写法、多个结果之间的轮换、每组的固定成本与消耗、整组怎么扣怎么返还。
- [06 来源层与覆盖](06-layers-and-overrides.md)：三层来源的优先级、用同 id 规则整条替换、停用或删除内置规则，以及多条规则抢同一个掉落物时听谁的。
- [07 服务端配置（server.json）](07-server-config.md)：`server.json` 每一项在管什么、默认值是多少，以及卡顿或转化节奏不对时该改哪里。
- [08 命令参考（/idtw）](08-commands.md)：全部命令、它们要求的权限，以及输出该怎么读。
