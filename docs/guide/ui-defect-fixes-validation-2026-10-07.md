## 验收步骤

建议先在截图所用 NeoForge 客户端执行下表，再在 Fabric 客户端核对同一组场景。

| 场景 | 操作 | 预期 |
|---|---|---|
| 树苗标签 | 打开“树苗落地 / Sapling Planting”，观察配方源标签，停留数秒，再点击标签容器 | 图标轮播真实标签成员；容器有展开标识；弹窗列出全部可预览成员，按钮及左右方向键可切换；展示文字不出现标签注册名 |
| 标签提示 | 悬停树苗标签、展开容器或目录中的标签 | 注册名只出现于 tooltip，文案为“支持所有带有 #minecraft:saplings 标签的物品”；数量与数量角标仍对应原规则 |
| 源物品对应方块 | 观察树苗配方的产出，展开该标签容器 | 显示真实树苗方块模型，并轮播源标签所对应的方块；不再将标签注册名当作普通物品 ID 查询 |
| 普通方块 | 查看完整立方体、台阶/楼梯、树苗、箱子的目录及预览 | 材质可辨认；绕自身模型中轴旋转；略俯视可见顶部；无环境遮蔽和落地阴影；整圈缩放稳定，模型不超框 |
| 鸡模型 | 查看“鸡蛋孵化 / Egg to Chicken”，观察至少一整圈；再检查幼年鸡和较高/较宽生物 | 头部、身体和脚完整；模型按实际顶点范围居中；不被容器顶部或相邻组件截断 |
| 不同 GUI 比例 | 切换 GUI scale，缩小/放大窗口，再查看上述标签和模型 | 容器布局与命中保持一致；模型完整，文字、数量角标与旋转模型不错误遮挡 |
| 搜索框 | 空搜索框观察“搜索”，输入文字、选中文字，然后打开弹窗 | 提示、输入文字、光标/选区均正常；弹窗遮罩覆盖底层文字及图标，物品不会出现在弹窗正文前方 |
| 弹窗 hover | 打开“放弃改动”，在弹窗外移动鼠标，并移到弹窗内部按钮；再打开两层弹窗 | 只有顶层控件进入 hover；底层不会产生新的 hover 或 tooltip；确认/取消/点击遮罩按原配置工作 |
| 滚动条拖动 | 拖动管理树及编辑页列表的滚动条，将鼠标横向拖入条目，保持按下再释放 | 拖动期间条目不进入 hover，且不弹行 tooltip；滚动条正常跟随；释放后普通 hover 和点击恢复 |
| 捕获结束 | 拖动中按 Esc 或用键盘打开弹窗，再关闭弹窗 | 底层拖动状态结束，返回界面后滚动条和列表不会保持被抓取状态 |
| 模型失效 | 打开预览后资源重载，关闭再打开编辑器或切换世界 | 使用新的模型资源，预览可正常重新测量；缺失或无法渲染的模型有兜底，界面仍可操作 |

## 已知限制

- 游戏内视觉、帧率及交互尚未实际验证，上表由用户统一执行。
- 模型测量基于 renderer 实际提交的标准 VertexConsumer 顶点，并由宿主缓存；不运行样例实体 tick。特殊第三方 renderer 若不能被测量，则实体退回加留边的估计范围，方块显示兜底。第三方模型随真实时间改变形状时，单次测量不能保证所有姿态都不超框。
- 本次没有新建 Mixin 或平台专用实现。kit 依赖方向、渲染/输入契约和精确白名单已记录在 [UI kit API](../dev/internals/ui-kit-api.md) 与 [NOTICE-kit](../../NOTICE-kit.md)。
