# 四阶段卡片界面人工验收

在 NeoForge 和 Fabric 客户端各执行一次；行为回归继续使用 [四页验收清单](editor-page-acceptance-2026-10-07.md)。本次清单用于布局和输入命中检查，尚未执行游戏内验收。

1. 使用 `/idtw config edit` 打开编辑器并编辑一条规则。依次查看基本、输入、触发、结果：页签铺满内容宽度，选中页为圆角蓝底白字，没有白色上下边和下划线；页头显示当前规则名和应用状态。卡片四角应平滑，没有突出的边缘色块。
2. 基本页检查规则 ID、显示名、恢复默认、启用、优先级、多行备注。不再有重复“基本信息”标题和“默认”标签前缀，数字输入与其它单行字段同高，备注至少能显示三行；输入文字应垂直居中。输入三行备注，拖动优先级并精确输入，点击恢复默认后撤销；字段和按钮均应可操作。
3. 输入页检查源物品、催化剂、流体三张独立卡片。物品项显示图标与本地化名，没有注册名编辑框；点击“添加”，输入名称片段，结果应逐字更新，不需要 Enter；输入 `#` 应只剩所属注册表的标签，删掉 `#` 应恢复普通目录搜索。一次添加物品和标签、点击叉号移除、使用 Delete 移除并撤销，检查条目恢复且输入／触发联动仍正确。开关展开后的字段必须留在对应卡片内，关闭开关后高度收缩。
4. 触发页检查横排选项、自然等待与条件卡片。增删条件、编辑叶参数、打开高级组合；输入页更改类型后，触发页仍对应同一个条件叶。无有效触发时仍显示缺失提示。
5. 结果页检查单方案直接显示动作，多方案仍能选择方案；切换物品／实体／经验和高级字段。普通产物预览应紧凑，实体预览仍可显示；拖动动作排序后撤销。
6. 分别在约 320×240、480×270、854×480 的 GUI 逻辑尺寸检查，或通过窗口和 GUI Scale 调整到接近尺寸。窄屏按钮可以换行，输入框不能被目录按钮覆盖，结果页可返回动作／方案；所有内容可通过滚动到达，底栏保持固定。
7. 切换简体中文和 English，检查卡片标题、按钮与页头；尤其检查长按钮换行后没有重叠。卡片边缘不应遮挡字段、列表或滚动条。
8. 滚动到页底后用 Tab 聚焦上一屏字段，检查自动滚动；拖动滑块或滚动条后在控件外释放，检查操作已结束。切页、打开弹窗后不得残留按下态。
9. 悬停页头应显示规则摘要和消耗提示。修改、撤销、重做、应用后，应用状态和按钮使能应相符；冻结期间编辑按钮不可操作，返回仍可用。

记录失败时提供平台、GUI Scale、窗口尺寸、语言、所在页与截图，以及能重复问题的操作顺序。

本轮数值与消耗补充检查：

- 数字输入框从 1 改为 12，未按 Enter 时滑条已移动；按 Enter 或点击其它字段后应可撤销。输入合法但超出常用滑条窗口的值应保持原值并显示溢出标记。
- 输入非法／未完成数字，不能被静默改成其它合法值；按 Esc 应恢复编辑前的文本和滑条位置。输入后先失焦提交，再次编辑并 Esc，应恢复最近一次提交的值。
- 拖动滑条时文本实时跟随；在控件外释放仍只提交一次，撤销恢复拖动前值。空的可选字段第一次编辑后 Esc 应恢复为空。
- 普通规则选择“自动”后说明每轮消耗 1 个；切换“指定数量”并设为 3，说明和实际字段应指向源物品每轮消耗量。已有消耗源物品动作的规则仍编辑该动作，不生成第二份消耗配置。
- 仅包含消耗催化剂或消耗流体动作的规则，在“自动”模式下应说明不消耗源物品，不能错误显示默认 1 个。

2026-10-09 精致化补充检查：

- 无自定义名称时，显示名输入框应显示与页头相同的实际默认名称，点击并失焦不能新增 `display_name` 或产生改动。修改名字后点击“恢复默认”，默认名应重新出现；撤销一次恢复自定义名。输入自定义名但不按 Enter，恢复按钮也应可用。
- 启用组件只占勾选框与文字宽度；点击其右侧空白不能切换状态，悬停没有 tooltip。优先级悬停应解释“同一物品匹配多条规则时数值越大越先尝试”，并说明相同数值的顺序及默认 0。
- 添加至少 6 个源物品，应有多个短卡片同排显示；缩窄窗口后按剩余宽度换行。检查换行后的叉号、上下左右键、Delete、撤销和三行以上的滚动条，尤其在滚动条外释放时不得误删物品。
- 添加一个含多个成员的源标签，观察至少 5 秒，图标应切换成员；普通物品图标保持不变。悬停标签卡片可看到真实标签 ID。
- 源物品只有具体物品时不显示黑名单；添加源标签后立即显示，移除最后一个标签后立即隐藏。撤销标签增删时显隐应同步。
- 添加两个不同源标签，打开黑名单添加页。每页只显示当前页标签成员，翻页标题应显示对应标签 ID；不出现无关物品或标签条目本身。跨两个标签选物品后确认，选项都应保留；重叠成员不能重复添加。搜索按字符过滤，空标签或无结果时显示可理解的空状态。
- 检查黑名单有超过 200 个成员的标签：同标签的子页连续，之后再进入下一个标签。冻结时无法继续选物品或确认写入。
- 打开旧规则：已有排除项不因隐藏而被清空；浏览、切页不应制造额外 JSON 改动。需要更改无标签规则的旧排除项时，应在规则文件中处理。
