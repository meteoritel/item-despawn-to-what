## 1. 提取结论与依赖边界

滑块应进入 kit：标量/区间/周期数值、粗细档、方向键、捕获和操作生命周期有多处复用，未来其它模组也能使用。现有 widget/UiSlider 直接依赖本模组主题、接口与草稿回调，不能原样搬入；提取核心、注入样式、由宿主适配数据。

kit 继续面向 Minecraft 客户端，不要求成为纯 Java UI 库。允许 Minecraft 客户端通用类型、Java 标准库、JOML、LWJGL、annotations；禁止引用本模组 Constants、core、client/edit、client/net、theme、screen、widget、Fabric/NeoForge API 或 Gson 业务对象。宿主可以依赖 kit，kit 不反向依赖宿主。

```text
规则模型 / 草稿 / 协议 / 目录缓存
              ↓ 宿主适配
字段元数据 + 页面控制器 + 主题 style/painter
              ↓ 通用值、Component、renderer、事件
kit：输入、焦点、捕获、布局、控件、泛型集合
              ↓
Minecraft 客户端渲染与通用输入类型
```

Component 文本、图标与说明由宿主传入，kit 不硬编码 `gui.itemdespawntowhat.*`。语义 formatter、单位转换、JSON 路径、ID/标签合法性和服务器限额留在规则编辑器。

## 2. 提取矩阵

| 能力 | kit 公开职责 | 宿主职责 |
|---|---|---|
| 通用 widget 输入 | bounds、render、可见/可用、事件消费、修饰键、焦点与捕获生命周期 | 从 Screen 采集状态，处理游戏连接与屏幕关闭 |
| 按钮/输入/勾选/分段选择 | 通用值、键盘交互、提交/取消、Component 标签 | 主题、文本校验、具体枚举、JSON 写回 |
| 标量滑块/步进 | 有限值域、粗细步长、指针锚点、键盘、preview/commit/cancel | 概率%、等级、tick/秒、可空与法定域 |
| 双端区间 | 端点选择、键盘/精确入口、边界约束、绘制与操作事件 | 每端是否可不约束、条件字段 min/max 的省略 |
| 周期区间 | 宿主指定周期、环绕高亮、端点、刻度/标记注入 | 24000 tick、0=06:00、昼夜预设与 JSON from/to |
| 列表/网格 | 泛型 item、稳定 key、可见行、选择、搜索输入/翻页意图 | 目录网络请求、缓存、过滤参数、结果关联 |
| 集合/重排 | 增删意图、拖动手柄、上下移、重复判定策略 | ID/TAG 模式、业务上限、不可删除项、结构写回 |
| 泛型树 | 节点适配、展开/折叠、选择、可见行、焦点与重排意图 | AND/OR/NOT、节点合法位置、深度/数量、条件路径 |
| 模态栈/组合焦点 | 顶层输入、防穿透、关闭意图、子焦点遍历与恢复 | 保存确认、断线、冲突、权限和草稿策略 |
| 图解原语 | 槽位、图标、分组、连接、分支布局及 renderer | 源/成本/候选关系、摘要；不做数量演算 |
| 主题注入 | 不可变 style、颜色/尺寸值或 painter，显示 focus/disabled/error | 灰色像素外观、素材、业务告警含义 |

“尽量提取”以有真实调用和清晰宿主接口为边界：不把整包机械移动，也不为将来尚未出现的需求建设插件框架。条件编辑器、规则标题、候选工厂与 SaveStatus 页面仍是业务实现。

## 3. 通用输入与公开接口轮廓

下列名称是建议名，实施时明确最小可用签名；这是职责契约，不是已发布兼容承诺。

| 建议接口/值对象 | 必须表达的内容 |
|---|---|
| UiWidget / 输入接口 | 渲染、位置尺寸、visible/enabled、指针按下/移动/释放、滚轮、key-down/key-up、字符输入；输入方法返回是否消费 |
| UiInputContext | 指针坐标、按钮、Shift/Ctrl/Alt 等显式快照；宿主提供，不在 kit 查询全局 Screen |
| UiInputCapture | 当前作用域捕获目标、结束/取消、原因；处理指针离开控件后仍能释放 |
| UiFocusTarget / 焦点作用域 | 复用已有焦点接口，组合容器提供子控件顺序；捕获不是焦点接口的业务职责 |
| UiValueInteraction | begin、preview、commit、cancel 事件及起始/当前值；数据回填不产生这些事件 |
| UiNumberPolicy / UiSliderWindow | 分别表达合法数值域与轨道显示窗口；普通/细步长、整数策略、键盘增量与拖动灵敏度，拒绝非法策略；不能用窗口边界拒绝域内值 |
| UiSliderStyle / painter | 轨道、已填充段、手柄、焦点、禁用、错误、文字槽；不 import 宿主主题 |
| UiRangeValue / 周期值 | 两端、选中端、周期与环绕表达；可选端状态独立于数值 0 |
| UiItemAdapter / renderer | 泛型稳定 key、展示 Component、图标/单元格绘制、选中与禁用原因 |

现有 `UiControl` 为 final，只承担命中/激活等能力，不强行继承以获得拖动。现有 widget 输入缺少鼠标 modifiers，先引入统一 kit 输入上下文，再用委托或接口桥接保留本仓库必要调用。开发阶段不为未发布 API 建立历史兼容层。

输入路由：确定顶层 modal 作用域 → 该作用域的捕获目标 → 聚焦控件 → 容器导航。事件只消费一次；打开 modal 前结束/取消背后捕获，不能让底层滑块穿透弹窗。`FormView` 当前先拦截 PageUp/PageDown，改为先给聚焦控件机会；仅未消费时滚动。普通方向键亦不能同时改值和滚动。

隐藏、禁用、卸载、焦点作用域切换和宿主关闭必须释放捕获；可调用统一结束入口，不能各控件随意提交。取消原因仅表示通用事件，是否失去服务器权限由宿主判断。

## 4. 滑块、步进与精确输入契约

### 回填与用户输入

- `setValue` 类回填操作接受合法值，不吸附、不回调、不产生编辑历史；越界/非有限回填应报告状态，由宿主决定如何显示非法字段，不静默改 JSON。
- 用户操作才按当前档吸附。整数粗细档均≥1；小数使用十进制步长，避免 0.1 连加的显示尾数；显示格式不限定存储精度。
- 滑块使用有意义的有限交互窗口；窗口不等于合法数值域。超窗口合法值仍显示和精确编辑，轨道可显示越出常用范围标记，绝不在打开时钳制。绝对点击只定位窗口，方向键/步进与精确输入覆盖合法域；大域不只靠轨道承担可达性。
- 点击轨道普通定位，拖动手柄捕获；Shift 采用较低灵敏度和细步长，不仅缩小吸附间距。
- 拖动时按/松 Shift 重设锚点，保持值不变；指针离开矩形仍接收释放。
- 默认 Left/Down 减、Right/Up 加；Shift 细调。Home/End 可达交互窗口端点，PageUp/PageDown 如启用大步需优先消费并提供说明；大域端点不靠不清晰跳转隐藏。
- 点击数值打开行内精确输入；输入解析、单位映射和错误由宿主字段适配提供，通用文本框负责缓冲、Enter/Esc、焦点。

### 一次操作生命周期

```text
外部回填 ──> idle（无事件）
开始拖动/按键 ──> begin ──> preview* ──> commit（改变时一次）──> idle
                                   └──> cancel（恢复起点）──> idle
```

宿主适配必须区分：preview 更新局部视觉；commit 验证并调用一次 EditSession.apply；cancel 丢弃预览。不能把现有逐帧 onChanged 直接接到深拷贝/持久化/撤销门面。

Esc 取消当前拖动；正常切页提交合法预览；失权/断线/禁用取消预览；同一次操作绝不能同时 commit 和 cancel。没变化不产生历史。连续方向键重复在 key-up 合并一条；页面切换或销毁时显式结束，不能留下捕获或悬空预览。

精确非法文本保留为宿主路径缓冲，不写数值；跨页错误阻止应用，关闭不保存成 JSON。整数解析、溢出、float/double 域、概率/秒数等详见字段规格，kit 不认识这些字段。

## 5. 双端与周期区间

普通区间保持 min≤max，拖到对端时停在相同值，不偷偷交换字段身份；键盘与行内输入可分别访问两端。端点命中重叠时提供当前端切换/焦点入口，不能永远拖不到其中一端。无约束端可由宿主关闭，底层状态不将其编码成 0。

单独编辑一端一条撤销；整体移动区间若提供则一条操作，不各端分别写草稿。没有当前需要时不添加额外区间手势。

周期区间不强制 min≤max：from>to 高亮跨周期，端点允许完整合法刻域；同刻表示单点，全天由宿主明确给出边界。宿主注入周期、刻度和图标，kit 不假定世界时间或服务器当前天气，不自行读取 level。

昼夜字段实际为整数 tick，普通拖动100、Shift1；精确入口允许任意0..23999。六个气候区间的普通0.1/Shift0.01为字段策略，不影响别的数值组件。具体可省略条件由描述符管理。

## 6. 目录、集合、树与模态

选择面板支持单/多选、图标网格/列表、当前选择、搜索、加载、空列表、错误和分页状态。以 callbacks 发选择/翻页/搜索意图；数据和网络完全由宿主供给。避免在 kit API 中出现 RuleCatalogKind、RuleCatalogEntry 或注册表提示常量。

`UiIcon` 现有 sealed Item/Sprite 能力继续复用，其它展示走泛型 cell renderer；不要仅为实体/流体格子解除 sealed。目录 labels 可能是翻译键或原文，由宿主解析成 Component。

现有 `UiListEditor` 的 ID/TAG、registryHint、本模组语言 key 与具体数量限额不适合直接通用化：提取集合操作，使用宿主传入的匹配/重复策略、添加内容和限额理由。kit 不硬编码 512 或 source 的256上限。

树节点使用稳定 key 与宿主适配，不把条件 JSON 挂进 kit。拖动发移动意图，宿主批准合法目标再提交；错误/超限状态由宿主传入。虚拟可见行与折叠不销毁必要选择身份。

模态负责子控件焦点序列；当前单焦点内容接口需补组合焦点，而不是假设整个弹窗仅一个按钮。顶层遮挡并消费输入，Esc 只处理当前层，关闭恢复打开前焦点；不可关闭场景由宿主配置，不写保存/权限逻辑。

结构图仅槽位与连接原语。将节点按宿主给定关系排布并支持窄屏纵向；节点点击可导航到相关页面，回调由宿主提供。不以图解 API 开发收益预测或运行模拟。

## 7. 来源、公开 API 与未来拆库

原 kit 来源为同作者 `unsuspiciousBlock`，提交 `625747e1f34ea957841d7136be4635469687c227`，23 文件原始清单见 [NOTICE-kit.md](../../NOTICE-kit.md)。原来源清单与原始行数保留，不能重写成“新 kit 全部来自原提交”。

实施时另记：修改/新增文件、来源版本、差异原因、公开接口变化、可回流状态。没有修改前不把 NOTICE 的“已知差异无”提前改成已实施；本次 ADR 仅记录维护方向。源项目不随本项目任务修改。

现有包仍位于本仓库，禁止 Gradle 绝对路径依赖来源项目。公开类用简体中文类注释、方法说明用中文行注释；包文档列依赖边界、输入路由、生命周期、style 注入和宿主示例。

至少给出两个无规则语义的调用示例：普通小数滑块（含 Shift/方向键/取消）和双端/周期区间（宿主刻度）。可利用现有 UI 原型入口展示，不增加绕过编辑权限的业务入口，不新增 test 文件。

未来拆库任务才确定中性 package、artifact/version、发布仓库、许可文本、跨 Minecraft 版本和多 loader 发行方式；本期不拍板不存在的坐标，不承诺 1.21.1 以外兼容。当前要保证 kit 源文件可以在不携带本模组业务包的条件下被组织为客户端库。

## 8. 实施顺序与验证

1. 定义输入上下文、捕获、操作事件与 style；修复 focus-first 路由，保留必要桥接。
2. 提取基础按钮/输入/开关/分段；实现标量滑块、步进和操作回填契约。
3. 实现双端与周期核心，补键盘、端点与精确入口。
4. 通用化集合/树/选择面板/模态与图解原语；由业务适配落实来源、限额、目录和编辑。
5. 逐步替换旧 widget 调用；没有真实使用的新抽象删除或延后，避免维护两套不同语义的控件。
6. 更新 NOTICE 与 API 示例；核查依赖后按项目顺序 IDEA → 串行 build，用户验收视觉与输入。

依赖检查可用源码 import 搜索加人工审阅；不假定仓库已有 kit 边界检查脚本。若需要自动化扫描，在实施任务内新增并记录，不能调用不存在的脚本。

完成条件：所有新增通用控件不反向依赖宿主；回填无事件，单动作单提交，取消/销毁释放捕获；键盘不被容器重复消费；布局在最低尺寸可用；样式/标签/renderer 可由另一个宿主提供；来源与差异可核查。此条件表示可复用准备完成，不表示独立库已经发布。
