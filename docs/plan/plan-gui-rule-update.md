## 3. 后端前置小任务

以下是 Q9 选定的**目标契约**，当前代码尚未满足。本轮只规划，后续分别实施；GUI 的运行说明依赖修正完成。

### B1：逐组候选选择与轮询

现状：`ConversionSettlement.plan()` 对整堆只选一次候选、推进一次游标，`dispatch()` 对全部组用同一 candidate。目标：每开始一组独立选候选；round_robin 从共享游标搜索能完成一组的候选，确定该组后推进；priority 每组从列表首项搜索。

验收：源量 4、成本 1、A/B 都有容量，从 A 开始得到 A/B/A/B；后续请求接续同规则与维度的持久化游标。容量不足时跳过；全部不可用则停止并返还未开始库存。概率落空不重选、不免费重试已开始组。

计划与派发结构必须在预算续跑中保留“本组已选候选、已预留成本、执行进度”，不能重进 tick 就重新选择或推进游标。保留共享预算、结构指纹、催化剂预留、结算快照与永久返还账本。

### B2：混合一次性效果

现状：`capacityGroups()` 遇到任一 oneShot 效果就封顶 1；[原行为契约 §2](../archive/backend-round-2/PLAN.md) 与 [ADR-0023](../adr/0023-triggers-fixed-cost-and-complete-group-settlement.md) 只限制纯一次性候选。

目标：含可重复效果的候选允许多组；oneShot 在同一源请求中只尝试一次，续跑不重试。概率失败与效果条件不满足也计为已尝试；状态按源请求与效果槽身份识别，不用翻译标题或编辑器当前数组序号。效果槽可由冻结规则快照、候选 id 和快照内槽索引确定，不新增效果 id JSON 字段。

验收：4 个可供消费的源、成本 1，候选包含生成物品和一次闪电，物品执行 4 组、闪电最多尝试一次；纯一次性候选仍最多一组。覆盖候选切换、容量不足、催化剂短缺、预算中断、重载与返还，不重复扣款、不重放已开始组。组数仅用于开发验收，不加入 GUI 计算器。

### B3：诊断与编辑基线修正

修正 `RuleValidation` 中 outcomes-only“当前版本不会执行”的过时告警。修正旧描述符的字段域、触发秒数单位、概率回填精度、药水等级上限和可省略标记。消费效果公共字段按当前模型保留，不套用 catalyst_cost 的严格白名单。

完成条件：B1/B2 行为与文案契约一致，B3 不再误导合法新规则；IDEA 检查与构建通过，游戏内行为交用户验收。

## 4. 页面与导航

```text
规则管理：搜索 / 筛选 / 模板或空白新建 / 草稿标记 / 选择 / 统一应用
  └─ 规则编辑：标题 + 启用状态 + 草稿/会话状态 + 撤销/重做
       ├─ 基本信息
       ├─ 输入与成本
       ├─ 触发与条件
       └─ 结果
       常驻：短摘要、未完成/错误、上一步/下一步、返回管理、应用
```

管理页沿用规则来源、作用域、启用、批量选择与草稿操作。搜索覆盖 id、人工别名、自动标题，其余现行筛选保留。基底规则删除/停用沿用覆盖控制条目，不把控制条目当产出规则。应用范围由当前选中草稿决定，不因进入某页就保存全部规则。

模板与空白共用规则/候选工厂和描述符：分配稳定 id、一个初始候选、固定源成本 1、当前 schema_version。空白草稿可暂缺源或效果，提示待完成并阻止应用；模板给可编辑初值，不另开保存路径。复制规则/候选分别分配新身份。

### 基本信息

- 人工别名输入与自动标题预览；“恢复自动命名”清除 display_name，一次可撤销编辑。
- 启用常见；priority 用步进/精确输入；notes 与技术 id 放高级区，schema_version 只读。
- 普通玩家无需编写技术 id；现有 id 不因改名、重排、切语言改变。

### 输入与成本

- source.items 匹配列表、source.exclude 排除列表；提供图标槽、目录搜索、ID/标签与精确 ID 输入。
- 每组源成本有“按规则推导 / 自定义”，未修改保持省略；新规则自定义 1，不提供 0。
- 催化剂成本开关，启用后编辑 items/count/radius；与 catalyst_present 分别解释“每组消耗 / 检查存在”。
- 现有 consume_source/consume_catalyst 映射到成本区时注明原路径，只更新原效果；禁止重复固定成本。其详情可定位查看，新增效果选择器隐藏这两类；consume_fluid 仍是效果。
- 图解显示源、配置成本、候选分支与效果关系及实际配置量；不放示例源数量、组数、余数或运行模拟。

### 触发与条件

- natural/fire/lava/cactus 可多选；省略/原空集合按有效 natural 展示。用户编辑后不能全不选再提交。
- 仅 natural 显示 trigger_after_seconds；取消 natural 保留值。其余方式在致命环境伤害导致消失时即时判定，不表示接触一次触发。
- 自然门槛依赖实际寿命，运行时在消失前处理；超出寿命的值不代表延长寿命，不承诺无限等待。
- 规则级 AND/OR/NOT 条件树与限额复用；区间、时间条和目录控件按字段规格接入。
- 普通区间不能交叉，昼夜可跨零点；不约束端与 0 分开，无条件省略 conditions，不写空组。

### 结果

宽布局为“候选列表 | 候选详情”，详情有独立效果列表/表单；窄布局为“候选列表 → 候选详情 → 效果详情”，返回恢复选择、滚动、折叠与焦点，不挤三个窄栏。

候选和效果均提供添加、复制、删除、拖动手柄与上下移；一次排序一次撤销，稳定身份与当前 index 分离，重排后重算 JSON 路径。删除后焦点落邻项。到 32 候选或全规则 32 效果禁止继续添加，临时空草稿仍可导航但不能应用。

显示“轮询 / 按顺序优先”；一候选说明仅该候选。safe_spawn、fill_origin 是候选策略，分别说明生物安全生成、方块起点填充；不适用时保留原值。

常用参数先显示，delay_ticks/chance/效果条件/容量/特殊策略折叠。内置类型走描述符；第三方已注册类型用扩展编辑器，无编辑器则只读保留并说明，不猜其私有字段。

## 5. 现行结构与 JSON 编辑

1. RuleDraft 原始 JSON 为事实源，修改走 `EditSession.apply`。回填、命名、单位、分页、折叠不写数据。
2. 顶层 effects 展示为单一隐式结果，可继续编辑；打开、改别名、改效果不自动生成 outcomes。
3. 用户添加第二候选或明确编辑候选专属策略时，简短说明“改为候选结果结构”，一次操作删除 effects、写 outcomes、保留原效果对象；整体可撤销。这是现行结构编辑，不建设迁移工具。
4. 候选只写 id/effects/safe_spawn/fill_origin；自动标题不写候选 display_name/notes。
5. 未改默认值保持省略，未知/第三方字段保留。保留不代表后端严格拒绝字段也能提交；原诊断须可见。
6. 非法旧开发样本不猜旧语义：当前可定位字段可修复，无法编辑对象只读，可用模板/空白重建，无自动转换。
7. 缺省、范围、路径见字段规格；作用域仍是实例 config 覆盖层或连接服务器目标，不暗示每世界独立配置。

## 6. 自动命名与稳定身份

采用本地化模板 + Component 参数，类似原版消息拼装；不通过中文片段拼英文。解析优先级为非空 display_name → 自动标题 → 安全兜底。notes 不命名。

技术建议：新规则 `itemdespawntowhat:rule_<32位小写UUID>`，候选 `result_<32位小写UUID>`；校验当前作用域/候选集合冲突。序号由位置计算，现有 id 不变，复制创建新身份。标题不写 JSON、不决定文件名、不改变游标指纹。

| 场景 | zh_cn 模板 | en_us 模板 |
|---|---|---|
| 单结果规则 | `%1$s：%2$s` | `%1$s: %2$s` |
| 多结果轮询 | `%1$s：轮询 %2$s 种结果` | `%1$s: Cycle through %2$s results` |
| 多结果优先 | `%1$s：按顺序选择 %2$s 种结果` | `%1$s: Choose from %2$s results in order` |
| 候选 | `结果 %1$s：%2$s` | `Result %1$s: %2$s` |
| 多效果 | `%1$s，另有 %2$s 项` | `%1$s, plus %2$s more` |
| 多输入 | `%1$s，另有 %2$s 项源` | `%1$s and %2$s other inputs` |
| 未完成 | `未选择源物品` / `未设置结果` | `No source selected` / `No result configured` |

多输入与多效果的第二参数均为除代表项之外的数量，只有多项才套该模板。“其它效果数”用同一筛选集合扣除代表项。主要效果优先第一个非源/催化剂成本效果；全成本则如实命名成本，不声称产出。图解仍显示完整结构。

| 效果 | 短标题 |
|---|---|
| spawn_item / spawn_entity | 生成 `%s` / Spawn `%s`，参数为对象可读名 |
| place_block | 放置 `%s` / Place `%s`；源方块分支用独立模板 |
| spawn_xp / loot_table | 生成经验 / Spawn experience；生成战利品 / Generate loot |
| lightning / arrow_rain | 召唤闪电 / Summon lightning；降下箭雨 / Create arrow rain |
| weather | 按 mode/thundering 显示放晴、降雨、雷雨 |
| explosion / consume_fluid | 产生爆炸 / Create an explosion；移除流体 / Remove fluid |
| consume_source / consume_catalyst | 消耗源物品 / Consume source items；消耗催化剂 / Consume catalysts |

标签用可用目录名，缺失显示 `#namespace:path`，不拿成员冒充标签；第三方类型走 TypeLabels，未知用 id。目录未加载用缓存/id，命名服务不发请求；源代表项按现有顺序取。

新 key 使用 `gui.itemdespawntowhat.edit.name.*`，en_us/zh_cn 同步。只读命名服务建议位于 client/edit，通过标签解析接口取宿主资源，不 import UI/网络/服务端运行时。列表、标题、候选、搜索和朗读共用；自动标题可重复，身份靠 id；截短不改变全文。

触发、条件、概率、成本由独立短摘要表达，不塞进标题。相关草稿分支、目录修订、语言变化时刷新，不逐帧遍历整条规则；别名原文不随语言改变。

## 7. 输入、草稿与会话

滑块默认方向键；整数步长≥1，小数按字段粗细档。Shift 拖动降低灵敏度，切档重新锚定当前指针和值，不跳变。回填不吸附，显示精度不反写。

| 事件 | 行为 |
|---|---|
| 拖动 | 捕获指针，控件与短摘要局部预览，不每帧调用 apply |
| 释放 | 验证最终值，一次提交；未变化无历史 |
| 拖动中 Esc | 回退开始值、释放捕获；不顺带关闭页面 |
| 正常切页/返回/关闭 | 有效操作先提交一次，再沿用草稿保留/离开提示；不自动发应用 |
| 隐藏/禁用/失权/会话失效/断线 | 取消未完成预览，释放捕获；已完成草稿保留 |
| 点击值 | 行内精确输入；Enter 提交、Esc 回退，无效文本不写 JSON |
| 精确输入中切页 | 有效值提交；非法缓冲与路径错误保留，返回可修正，应用被阻止；关闭不持久化非法文本 |
| 方向键重复 | 一次按键重复聚合到 key-up；失焦/导航按同一结束策略处理 |
| 切单位/折叠/选择 | 仅 UI 状态，不增加撤销 |

沿用基线版本、撤销/重做、草稿日志及 `config/itemdespawntowhat/client/editor-drafts`。新增嵌套操作和选择适配，不另建保存系统；预览不深拷贝整条 JSON。恢复比对基线，冲突不自动覆盖。

上行统一经 `RuleEditClientWorkspace`。沿用 permission level 2、服务器目标独占锁、15 秒确认、10 秒心跳、60 秒租约和服务器活动 tick；单人暂停不能用墙钟误报失效。失权不能通过 GUI 绕过命令重开会话。

应用前结束有效操作、收集选中草稿、校验必填/限额/缓冲错误，再走变化集和版本戳。请求中禁止重复提交，保留位置；按 statusCode 分支，不解析说明字符串。

| 状态码 | 行为 |
|---|---|
| SUCCESS / NO_CHANGES | 按结果重设基线与已应用草稿，保留活动会话和选择 |
| VALIDATION_FAILED | 保留草稿，定位规则→页签→候选→效果→条件→字段 |
| VERSION_CONFLICT | 刷新快照，显示基线对比，供恢复选择，不自动覆盖或保存重试 |
| NO_PERMISSION / LOCK_NOT_OWNED / LOCK_BUSY / SESSION_EXPIRED | 取消预览，停用写入，保留草稿；说明从现有命令重开 |
| WRITE_FAILED | 保留草稿与诊断，问题解决后可重试 |
| SAVED_NOT_RELOADED | 明确“磁盘保存成功，运行时重载失败”；取权威快照核对基线，不盲目重写 |
| INVALID_REQUEST / UNAVAILABLE | 保留草稿、说明原因，按会话状态刷新/重开，不假装成功 |

定位同时支持 effects[j]、outcomes[i].effects[j]、递归 terms/term/condition。先记节点身份再映射当前 index，排序后不能跳错对象；未知路径至少落对应规则与问题区，不抛异常阻止打开。

## 8. kit、目录与视觉

**滑块及可复用组件进入 kit API**；先统一输入/样式/生命周期，再提取，详见配套 kit 规格。主题、单位、规则、目录、草稿和撤销由宿主适配。

最低 320×240 GUI 逻辑坐标用单列与分层，宽空间才并排；断点按可用内容宽度，不按显示器分辨率。检查大屏、scale 1/2/3、中英文；灰色像素边框，缺贴图不阻塞功能，颜色辅以文字/图标，长名称 tooltip。
