# 预检查冻结计划，以完整转化组结算

状态：第二轮规划已确认，尚未实施。

销毁转化、结果组合与跨 tick 延迟使源物品可能在效果执行前已经不存在。采用转化前检查并冻结条件和概率，源与催化剂使用正数固定成本，以完整组进行库存结算；流体只作存在条件，不预留份数。已开始组支付完整成本，突发动作失败记录实际结果而不补做；正常卸载或停服终止后，仅返还尚未开始部分。

选择此方案，避免反复环境校验改变已确认转化，也避免原有固定 rounds 与实际产出脱节。放弃世界效果回滚和恢复未完成组的复杂度，接受已开始组可能付出成本但产出不完整；真实生成数必须单独记录，预检查不能冒充执行成功。预留库存、源所有权与待返还记录防止源已死亡、重复占用成本或中断时吞掉未消费部分。
