# 第二轮掉落物转化术语

本词汇表记录 grill 已确认的第二轮领域语言；不代表当前版本已经实现这些行为。

## Language

**销毁转化**：由火、岩浆或仙人掌造成的掉落物销毁所触发的后续转化。
_Avoid_：非自然消失转化（未限定消失原因时，范围过宽）

**即时转化**：满足触发与转化条件后，不设置额外转化等待时间的转化。
_Avoid_：接触转化（单纯接触危险源不触发销毁转化）

**消失方式**：触发掉落物后续转化的消失原因；本轮讨论的自然消失、火、岩浆和仙人掌互为并列选项。
_Avoid_：转化条件（消失方式与规则的其他匹配条件需分别描述）

**环境保护**：掉落物免受火、岩浆和仙人掌伤害的保护状态；新产物采用定时保护，返还掉落物采用永久保护。
_Avoid_：转化冷却（保护与冷却为不同状态）

**转化冷却**：掉落物暂时不能再次触发转化的状态；冷却期间被真正销毁仍会正常消失，不延后执行销毁转化。
_Avoid_：环境保护（冷却本身不提供伤害保护）

**返还掉落物**：未完全转化时返还的源物品剩余部分，不属于新生成的转化产物。
_Avoid_：转化产物（会混淆输入剩余部分与转化输出）

**转化组**：按配置消耗固定数量源物品并执行对应效果的一组转化，是不可按比例拆分的结算单位。
_Avoid_：执行批（执行批是调度分批，不代表消耗结算单位）

**已开始组**：已经支付固定成本并开始执行的转化组；效果突发失败不会使它重新变为可返还的未开始组。
_Avoid_：成功组（开始执行不保证所有效果成功）

**候选结果**：一个转化组可选择的结果，内部可以包含多个共同执行的效果。
_Avoid_：效果（候选结果与其中的单个效果不是同一层级）

**组合模式**：从多个候选结果中选择一个的方式；支持轮询和优先，默认轮询。
_Avoid_：效果排序（组合模式决定选择哪一个结果，不表示所有结果都会执行）

**一次性效果**：对同一个源掉落物最多尝试一次的效果，例如天气、爆炸或闪电。
_Avoid_：无上限效果（没有容量上限与尝试次数是不同概念）

**转化禁用**：返还掉落物在本实体整个生命周期内不能再次参与转化的状态；拾取后重丢不继承，原版自然消失仍可发生。
_Avoid_：永久冷却（与会自动结束的转化冷却区分）

**安全生成位置**：在转化起点水平 5×5、上下各 2 格内，符合目标生物体积、环境与地面或水域要求的生成位置。
_Avoid_：安全区域（实际生成需要明确的位置）

**起点填充**：方块放置优先尝试转化起点所在方块位置的可选行为，仍受可替换性和合法放置要求约束。
_Avoid_：清除危险源（起点填充不保证消除邻近危险源）
